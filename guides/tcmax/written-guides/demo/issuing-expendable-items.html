Issuing Expendable Items

info

Items with the ‘No Turn-In’ box checked are considered Expendable Items. When checking this box, it automatically checks the ‘Multiple items with this same barcode number’ box.

Items with the ‘Issue multiple of this item with single scan’ box checked causes TCMax® to ask how many of these items you wish to take.

  1. Type ‘02’ in the Main Input box then press the ‘Enter’ key, TCMax® says “User”.

  2. Type ‘Building 99’ in the Location box then press the ‘Enter’ key, TCMax® says “Location”.

  3. Type ‘702’ in the Main Input box then press the ‘Enter’ key, TCMax® says “Enter Quantity”.

  4. Type ‘6’ in the Multi-Item Issue box then press the ‘Enter’ key, TCMax® says “Issue” and the ‘Quantity On Hand’ and ‘Quantity Available’ on the Main Screen decreases by two.

  5. If your ‘Quantity On Hand’ of this item goes below the “Reorder Qty” then TCMax® will announce “Attention” to tell you that you need to reorder this item.

    ➤ Your Expendable Items issued will only appear under the Users Expendables tab when a User is displayed on the Main Screen of TCMax®.

  6. Press ‘Esc’ key to clear the Main Screen.
