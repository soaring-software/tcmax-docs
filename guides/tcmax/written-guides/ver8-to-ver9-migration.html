Version 8 to Version 9 Data Migration

info

A video walkthrough is available for this process here.

tip

It is recommended that you reach out to TCMax® Support Staff for assistance on migrating your Data

To begin migration you will want to have TCMax® Version 9 installed and licensed on your destination computer as well as your Version 8.10 Microsoft® Access Database (if standalone) or access to the Microsoft SQL Server®.

note

If you are running 8.9 or earlier you must first upgrade to 8.10.590.

Getting Started​

Within TCMax® Version 9, navigate to File > Import / Export Records.

We can migrate Data from both Microsoft SQL Server® and Microsoft® Access Databases. Therefore, the remainder of this outline is split up into two categories, Migrating your Data from a Microsoft SQL Server® and Migrating your Data from a Microsoft® Access Database.

Migrate from Microsoft SQL Server®​

If your Version 8 Data is in a Microsoft SQL Server® Database, select the SQL Server radio button and then click the Set Source button which will bring up a Connections Properties window.

Enter your Server Name, Authentication Method, and Database. Click the Test Connection button and if it says “Test connection succeeded” you can click OK to proceed.

If it gives any result other than “Test connection succeeded.” take note of the error indicated and correct the connection information. When finished select OK.

Select the Set Destination button and follow the same steps, except in this case you will enter the destination server’s information. When finished select OK.

Step One: Verify Source Database​

To verify that your source Database is up to date and all datatypes are correct you will need to select the Verify Source Database button. This step is not optional and must be completed before progressing to step two.

Step Two: Sync Data​

Once your Database has been verified, select the Sync Data button to move the Data into your destination SQL Server Database. During the sync, information will appear on the screen letting you know what step of the syncing process you are on.

Step Three (Optional)​

You can remove any old Database tables that will no longer be used by TCMax® by clicking the Remove Old Data button. By opting to leave Old Data, you will notice all the Version 8 tables will still remain intact but will essentially be 'archived' Data from the migration point.

Finished​

Your Data should now be migrated and by re-establishing your TCMax® connection to the destination server you should see all your Data available.

note

Often times, unless the destination server Database was empty you will need to enable the new Shop Code within Settings > Sites and Shops.

Migrate from Microsoft® Access​

note

If migrating a standalone Database (Microsoft® Access), you will need to be on TCMax® version 9.8.7802 or older. This feature is removed due to deprecated Microsoft Software. If you are using a newer version of TCMax®, contact the Soaring Software Solutions support office for assistance.

If you are using a Microsoft® Access Database, select the Access radio button then select the Set Source button to bring up a File Explorer window that can be used to navigate to your Microsoft® Access Database. Ensure your Microsoft® Access Database is local to this computer's hard drive and not on a media or networked location. Locate and select your Microsoft® Access Database and press Open.

Set your destination Database by selecting Set Destination or by leaving this default, your Data will be migrated into the currently established connection (the Database you are working in).

After you have chosen your Microsoft® Access Database and your destination Microsoft® SQL Database proceed to the next step.

Prerequisite: Transfer Access Database to SQL Server​

This process requires you to have SQL Server Migration Assistant (SSMA) installed on your computer and also requires some form of the Microsoft® Access Database Engine.

By selecting the Transfer Access Database button, TCMax® will launch a command line window which will pause early on and prompt you (indicated green) to enter a password for the Microsoft® Access Database.

When prompted, enter the Database password and press Enter on the keyboard. The default Database password is Servic1. Once the password has been entered the query execution will resume and may take some time. If there are no issues you will be taken back to the migration window and may proceed to the next step.

Step One: Verify Source Database​

Once SSMA has moved all of your old Version 8 Microsoft® Access Data into temporary tables in your new Database, select the Verify Source Database button which will verify the old Microsoft® Access Data is complete and ready to be synchronized.

Step Two: Sync Data​

Select the Sync Data button to move the Data to your Microsoft® SQL Server Database. During the sync process, you will provide input to different prompts, outlined below.

Tool Chits Migration​

Select Shop Code​

Migrate Special Options Data​

This window is used to let us know how the Data needs to be copied based off of the options you were using in Version 8 of TCMax®.

Select the Shop Code(s) that you would like to run the tool against and click the Migrate button under the Special Options that you were using. Once this is finished you can select the Close button to close this window and return to Migration screen.

Step Three (Optional)​

You can remove any old Database tables that will no longer be used by TCMax® by clicking the Remove Old Data button. By opting to leave Old Data, you will notice all the version 8 tables will still remain intact but will essentially be 'archived' Data from the migration point.

Finished​

You can now select Close and verify your items have migrated to your destination Database.

note

Often times, you will need to select the new Shop Code within Settings > Sites and Shops.
