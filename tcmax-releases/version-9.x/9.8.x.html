Version: 9.x

9.8.x

Change log for all TCMax® Asset Management Suite releases of 9.8.x.x.

info

Version 9.8 is the current stable release of the TCMax® Asset Management Suite.

Version 9.8 requires an update to the Database if moving from a previous version of 9.x.

Clients running version 9.7 can continue to operate correctly when connected to a Database for version 9.8.

Clients running 9.6 and earlier need to be updated to a version of 9.8 or 9.7.
