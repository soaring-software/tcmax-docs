Version: 9.x

9.7.x

Change log for all TCMax® Asset Management Suite releases of 9.7.x.x.

9.7.7478.25849 - 2020-06-11​

Added​

  • Added dpi scaling issues.
  • Added total count issued when user is scanned on main screen.
  • Added ability to override certain options.
  • Added additional responsiveness to main screen based on selected shop code.

Fixed​

  • Fixed dpi scaling issues.
  • Fixed issue where main screen grid positions were not saving.

9.7.7383.24125 - 2020-03-23​

Added​

  • Added logging functionality to general inventory mode (with report).

Fixed​

  • Optimized assets verification processes to improve performance when scanning a large kit.

9.7.7355.19485 - 2020-02-24​

Added​

  • Added a new option to look across shops for barcode uniqueness.

Changed​

  • Settings have been moved into individual files.

Fixed​

  • Fixed work location buttons form, improved speed and stability.
  • Adjusted Dashboard queries to improve performance and accuracy.

9.7.7202.16222 - 2019-09-20​

Changed​

  • Updated user site permissions.
  • Updated US Navy reports.
  • Improved logging performance for inventory modes.

9.7.7068.17062 - 2019-05-09​

Fixed​

  • Fixed printing AF1297 from temporary deployment screen.

9.7.7054.20187 - 2019-04-26​

Added​

  • Added support for the F9 prefix key shortcut to additional screens (Example: Item Search, Temp. Item Transfer, Inventory, etc.)

Fixed​

  • Fixed an issue with the facility keys.

9.7.7027.26937 - 2019-03-29​

Added​

  • Added support for UID barcodes outside of the main form.

9.7.7024.25016 - 2019-03-26​

Added​

  • Added additional search fields in the Item Search screen.
  • Added/updated reports for US Navy and Marines.

Changed​

  • Deployment return specified item feature updated to support all configurations of deployments.
  • Updated the Army 2062 to fill out the user receiving assets.

Fixed​

  • Fixed an issue with date time conversions sometimes falling below minimum date time offset.

9.7.6995.19309 - 2019-02-26​

Added​

  • Added a new mode for chits that allows turning off the chit assignment to users.
  • Added additional fields for printing in the label maker software.

Changed​

  • Deprecated inventory modes have been removed from the software.
  • Changes to barcode printing on the MIL report.
  • Updates to the AF244 report.

9.7.6978.24905 - 2019-02-08​

Added​

  • Added a new option for users on Local DB that have multiple Windows accounts per machine. This option will shutdown the application when a user locks their account to free up the service running Local DB for the next user that logs in.

Fixed​

  • Fixed an issue in the label maker software that could throw errors depending on the fields selected for printing.

9.7.6970.21716 - 2019-02-01​

Changed​

  • Improved performance for copying database records between TCMax® databases.
  • Improved performance for deployment procedures.

Fixed​

  • Fixed an error in editable item search that was not allowing dates to be recorded based on how the grid was sorted.
  • Rewrote the serial communication components to fix an issue where the base .NET implementation would cause a memory leak leading to slowed performance in the software.

9.7.6890.23658 - 2018-11-20​

Added​

  • Added package manager for importing and exporting custom reports, charts, and status trackers.

9.7.6725.15322 - 2018-06-06​

Changed​

  • Improved performance of inventory modes in the software.

9.7.6711.24997 - 2018-05-17​

Added​

  • Added collation checking to the import scripts for customers running a database with a different collation than the server it is being hosted on.

9.7.6702.24181 - 2018-05-09​

Fixed​

  • Various bug fixes and stability improvements.

9.7.6656.19354 - 2018-04-12​

Changed​

  • Changed how report caching operates to fix an issue caused by the latest Air Force SDC release.

9.7.6634.17547 - 2018-03-13​

Added​

  • Brand new inventory modes designed from the ground up.
  • New restocking modes available for kits after physical inventory.

Changed​

  • Kit builder redesigned for easier creation and customization of kits.

9.7.6613.23144 - 2018-02-12​

Added​

  • Brand new inventory modes designed from the ground up.
  • New restocking modes available for kits after physical inventory.

Changed​

  • Kit builder redesigned for easier creation and customization of kits.
