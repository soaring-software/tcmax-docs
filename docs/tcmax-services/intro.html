Introduction

Introduction to additional services for the TCMax® Asset Management Suite.

  • Overview
  • Software License Agreement
  • Trademarks

TCMax® currently offers a console for managing several server-side applications used for various operations known as the TCMax® Service Console.

Services will be installed as a Windows service, and may be started, stopped, and configured via the TCMax® Service Console. Once installed and configured, the services installed will run autonomously without requiring you to manage them.

The TCMax® Service Console currently allows you to manage the TCMax® ATC Sync Service. Previously referred to as ATC Sync/Bridge.

The TCMax® ATC Sync Service syncs employees, issued items, logs, and more between TCMax® and ATC. You can also manage the TCMax® Emailer Service via the TCMax® Service Console.

If the TCMax® ATC Sync Service is going to be used, the TCMax® Service Console is recommended to be installed on the server that is hosting the TCMax® Database. To ensure service uptime, we do not recommend installing the TCMax® Services Console on a user’s desktop / client computer. Only one instance of TCMax® Service Console should be connected to any given TCMax® Database.
