Email Settings

Email Settings can be configured from the Service Console or from within TCMax® by navigating to Settings > Email Options. All the listed triggers will allow you to enter a Subject which will be the subject of the email and a Message which will be the message in the body of the email along with details related to the trigger.

Recipient Message Settings​

Start by selecting the category you would like to setup automatic emails for. When expanding the category you will see the settings for the recipients along with other options such as Subject line, Message, Occurrence, Part Number, Report, etc.

The image provided below will show the details and options within the Calibration category.

Choosing Recipients​

To choose the recipient(s), click the box Select Email Recipient(s) button and the Email Selection window will display, allowing you to select from Email Addresses added to your users.

Simply select the email(s) you wish to assign to to the trigger and move them to the right box by selecting the button.

Adding New Emails​

If you would like to provide an email that is not a current user in the Database, you can do so by selecting the Add New Email button.

Click Accept when finished to return to the Emailer Configuration window.

Options​

Part Numbers​

Several of the email triggers have Part Number settings that can be implemented. In the grids that contain the Part Number and warning level, you can set it so that the email will only be sent if the number of items with the Part Number entered has reached the warning level.

The Only send an email for the following part numbers checkbox will set a threshold for the emails to be sent out only for the Part Numbers entered into the grid that exceed the warning level.

note

Part Numbers are not required, and if the checkbox to Only send an email for the following part numbers is left unchecked than an email will be triggered for all items being marked as lost, broken, etc.

Schedule​

Several of the email triggers have a schedule that can be set. In the Email sending schedule, you can configure when and how often an email gets sent regarding the trigger.

tip

By not providing an Occurrence, you can configure an email to be sent one time on the date and time of your choice.

Categories​

Lost Status will send out emails concerning items that get marked as Lost.

Broken Status will send out emails concerning items that get marked as Broken.

Unserviceable Status will send out emails concerning items that get marked as Unserviceable.

Long Term Status will send out emails concerning items that get marked as Long Term.

Reorder Status will send out emails concerning items that have dropped below their reorder quantities. The emails can be sent out either at a specific time of day or periodically, depending on which option you select.

Issued Items At End of Shift will send out emails concerning items that remain issued out to a user once the end of their shift has elapsed. For this report to be effective you must be using the shift feature in TCMax® found by going to Settings > Shift Setup from the Main Screen. You must have the shifts created and assigned times and the employees must be assigned to a shift.

You can set the amount of time after the end of the shift to send a warning email to the relative user and the amount of time after the end of shift to send out emails to the designated recipient(s).

Calibration will send out emails concerning items that are overdue for calibration or becoming overdue within a window of days.

Inspection Status will send out emails concerning items that are overdue for inspections or becoming overdue within a window of days.

Transfer Alert will send out emails concerning items that have been transferred either into or out of the Shop Code that the email has been set up for.

Secure Inventory will send out emails concerning items that work in conjunction with CompX® locks provided by ekProtrack to notify the user about unauthorized access and unsecured closures of the lock system.

Custom Reports can send user generated reports as emails if the report requires no input from the user (parameters). You can select the report you would like emailed from the list on the left side of this section and input the recipient and email information in the appropriate areas. You can then set the date and time for the initial email as well as the schedule for the email.

This section also allows you to Add Event(s) for the trigger. Allowing you to have a set schedule along with immediate attention after a specific trigger occurs.

warning

Any report that requires user input will not be able to be sent via the emailer. This includes mandatory barcodes, dates, or any additional parameters that TCMax® has built in or users have included in custom reports.
