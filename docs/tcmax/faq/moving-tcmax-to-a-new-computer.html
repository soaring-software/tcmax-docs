How to Move TCMax® to a New Computer?

This section of the Documentation will contain instructions on moving a TCMax® installation to a new workstation.

If you are not moving TCMax® to a new computer, skip this section.

If you are upgrading from TCMax® Version 8 to Version 9.X, please follow the installation instructions, then refer to the Migrations section to bring the Version 8 Data into the Version 9 Database.

Transferring TCMax® to a New Computer​

To transfer the TCMax® installation from one computer to another, you will need to determine what your current configuration is and what settings/files need brought to the new computer.

Preparing TCMax® Settings​

To bring the TCMax® settings to your new computer, save them to the Database. Open Settings > Options and select the Captions and Presets tab. Save the settings in the Database with a name of something meaningful to you so you can recall the settings later.

In the "Custom Option Presets" group box, select New Preset then select the Save Custom Preset button. You will then be prompted to enter a name. Type the name of your settings and hit OK. Remember this to restore your settings later.

Moving the Attachments and Pictures Folders​

To move the attachments folder, you must first identify if the attachments TCMax® is referencing are stored locally or on a network location. To identify this, access Settings > Options and expand the Display Options section. At the bottom of this section, you will see a group box for Picture and Attachment Path.

If the path starts with C:\ it is most likely a local path. For other drive letters, you will need to reference your Windows settings to see if they are network drives.

Local Attachments Folder​

If the attachments are saved locally, copy the folder (in this case, the folder is called Images) to your transfer media. Once the new computer is set up, you will retrieve this folder from this media.

Networked Attachments Folder​

If your attachments and pictures are stored on a network drive, and if you are reconnecting to this network, make note of the folder path so you can manually connect to it from the new client install.

If you do not plan on reconnecting to this network and would like to cease sharing the files, follow the steps for Local Attachments Folder.

Moving the Database​

To identify what type of Database you are connected to, open the Help > About screen. Near the top of this screen, below your license and support information, you will see Data Source and Database fields. If your Data source fields includes "(LocalDB)" and you can see the Database Location field, then you are connected to a LocalDB instance.

If the Database location field is not visible, then you are connected to a Microsoft SQL Server® instance.

Local Database​

If you are using a LocalDB, you can use the backup feature of TCMax® to create a copy of your Database. File > Backup Options > Current Path will display the location where your backups are being stored. Make a backup by selecting the Backup Database menu option or pressing F11 on your keyboard. Retrieve your backup from this folder (it will be titled the Database name with the date and time) and place this on your transfer media.

SQL Server Database​

If you are using Microsoft SQL Server® and plan to use this Database locally, you will need your Database Administrator to create a backup of the Database using Microsoft SQL Server® Management Studio.

If you plan to reconnect to the networked SQL Database, you will only need to know your login information for the Microsoft SQL Server® connection. You can find this information from the About screen (except for passwords).

Un-Licensing the Original Installation​

To remove your TCMax® license from the machine which you will no longer be using, you will need to launch the Soaring License Manager from the Programs > TCMax folder of your Windows Start Menu, or you can launch the program from C:\Program Files\Soaring Software Solutions, Inc\TCMax. You will need administrative privileges on this computer to use this utility.

To Deauthorize this computer, select the Deauthorize button on the license you would like to remove.

Prepare the New Computer​

To prepare the new computer, install TCMax® on the computer. Once installed, you will have the files necessary to continue. Do not start TCMax® yet.

Restoring the Database​

LocalDB Database​

To restore a LocalDB, you will first need to connect to a new blank Database, then from within the software, you can restore to your backup from the previous computer. For ease of use, place the backed-up Database from your transfer media to a safe place on your new computer, and start TCMax®. It will ask you for the Database you would like to connect to. By default, you should see settings for a LocalDB connection.

If your window appears as the image above, hit OK.

If there is not a Local Database in the location specified, you will receive the following message.

Select Continue and TCMax® will create the Database files in the designated location.

TCMax® will now ask you to license your installation, this will require administrative privileges to start the Soaring License Manager. From within the License Manager, select the Add/Modify button and you will be presented with the licensing screen.

Your company/unit license credentials can be located from the license certificate or by viewing the license information page from the Soaring Software Website (www.soaringsoftware.com).These credentials are case/space sensitive and the License Manager will display a green checkmark when the information has been entered successfully. Once a green checkmark is displayed, select Activate to apply the license.

TCMax® will now ask you to include Demo Data. To proceed with the restore it is advised to include Demo Data as this will speed up the process of restoration.

tip

If Demo Data is not included, TCMax® will ask you to create a Shop Code and an Administrator User.

TCMax® will now tell you ‘No Shop Codes Selected’.

Press OK through the No Shop Codes Selected screen, where you will select a Shop Code. TCMax® will now display a Sites and Shop Codes Screen.

If you did not include Demo Data, you will need to create a new shop code here.

If you included Demo Data, you will see the 'TCMax Demo Shop' that can be selected.

After you have selected the 'TCMax Demo Shop' or the newly created Shop Code, press Save.

If you did not include Demo Data, TCMax® will ask you to create an Admin User.

Select Yes. TCMax® will display the User and Item Barcodes screen. This screen will allow for you to configure the User's and Item's barcode character counts. Press Save once/if information is modified.

note

This information can be changed once the restore has been completed. For ease of use, just accept the defaults and make note that a '2' digit Barcode Id can be used to create your temporary Admin User.

You will then be prompted to create an Admin User and Password. Make sure to note the User Id and Password as you will need them to log in and perform the restore from the next steps.

If you included Demo Data, see the steps below for further guidance.

TCMax® will now ask you to log in to the Database.

Log in using the built-in Demo Admin. The User Id is “01” without the quotes, and the User Password is also “01” without the quotes or log in with the Admin User credentials that were created in the previous step.

Once logged in, go to File > Database Maintenance. TCMax® will display another login screen to verify permissions to the Database Maintenance screen.

Log in using the built-in Demo Admin. The User Id is “01” without the quotes, and the User Password is also “01” without the quotes or log in with the Admin User credentials that were created. Once logged in to the Database Maintenance screen, go to the Backup Database tab.

Once on the Backup Database tab, select Restore Database.

TCMax® will display a Restore Database screen verifying you want to restore your current database, select Yes. Once Yes is selected, TCMax® will open a File Explorer window where you will find and select your backup file to restore to.

Once the backup file has been selected, TCMax® will display a Backup Restored screen. Hit OK.

TCMax® should restart (in the event the Software does not relaunch automatically, go ahead and relaunch the Software manually). Once the Software has relaunched, you will see a 'No Shop Codes Selected' screen displayed.

Press OK through the No Shop Codes Selected screen. TCMax® will now display a Sites and Shop Codes Screen where you can select your Shop Code(s). Once your Shop Codes have been selected, press Save. You will now be prompted to log in to the Database.

Log in to the Database with your User account credentials from your previous TCMax® client.

SQL Server Database​

If you are connecting to an instance of Microsoft SQL Server®, have your Database administrator restore your Database using Microsoft SQL Server® Management Studio, and when prompted, enter the information to connect to your Database. You will then need to license your software.

Restore TCMax® Settings​

Once you are reconnected to your Database, open Settings > Options and click on the Captions and Presets tab. In the Custom Options Presets group box, you will see the drop-down list of your saved settings. Select the setting you created in the previous steps and choose Load Custom Presets.

Restore Attachments and Pictures Folder​

If you are connecting locally to attachments, place your attachments folder from the transfer media to a public location on your computer (most commonly C:\Users\Public\Documents\TCMax). In the General Options tab of Settings > Options, expand the Display Options. Find the Picture and Attachment Path then select the Set Path button, making sure to select the folder that was just copied from the transfer media.
