Issue/Turn-In

Issue/Turn-In is the normal mode of operation and is used for all the issuing and turning in process.

When you switch to another mode of operation you can return to Issue / Turn-In by clicking the mode menu option. When you shut down and re-start TCMax®, it always reverts to the default Issue / Turn-In mode (unless an option is checked to have TCMax® start in a different mode).

Issue/Turn-in Instructions can also be viewed by pressing next to the input box

Issuing Items​

Step 1: Enter the User Id of the User Receiving the Items​

Enter or scan a User Id in the input box for the user who is receiving items.

When a user is displayed, the Event Log table (lower left quadrant) switches modes and displays all the items that this user currently has issued to them.

Step 2: Enter Location (Optional)​

Scan or type in the Location that the user is taking the item(s) to.

Step 3: Enter Item Barcodes​

Enter or scan the Barcode Id(s) of the items the user is taking.

  1. If the item’s Issue multiple of this item with single scan check box is checked from the Quantity and Status tab on the Main Screen then you will hear the audio Enter Quantity and an input box will appear on the screen asking you how many items you want to issue. Enter the appropriate quantity and press the Enter key.
  2. If the item is not yet issued out, then the audio Issue is heard telling you that the item has been issued.
  3. If the item was previously issued and was not properly turned in, then TCMax® responds with the audio Turn In telling you that the item has now been returned. In this case immediately re-scan the item. The Issue audio is now heard, and the item is properly issued.
  4. If the item that you are issuing is overdue calibration or has a “child item” that has an overdue calibration, then the Overdue Calibration audio warning is heard. It is followed by the Issue audio if the user the items are being issued to has permission to adjust calibration dates otherwise the item is only displayed.
  5. If the item that you are issuing has a “child item” that has already been issued (like a torque wrench sent to the calibration lab) then the Caution-Item Removed audio warning is heard followed by the Issue audio.
  6. If the item that you are issuing has an inspection that is overdue, then the Inspection Overdue audio warning is heard. That is followed by the Issue audio if the option has not been turned on to prevent the issue of overdue inspection items.
  7. If you have set the warning lead time in Settings > Options for calibrations or inspections to a specific number of days other than zero and this item calibration or inspection date falls into the lead time area (but it is not overdue) then a Calibration Imminent or Inspection Imminent warning appears, and the item can be issued.

Step 4: Clear User from Main Screen​

After issuing items to the displayed user, hit the ESC key to clear out the current User Id or scan the next user that you need to issue items to.

Turning Items In​

To check in an item, all you need to do is enter the item(s) Barcode Id.

If you are turning in items, it is not necessary to enter a User Id (unless Settings > Options > General Options > Turn in Options requires it).

While turning in items, if the User Id is first entered then the Event Log table (lower left quadrant) switches to display the list of items that are out. This helps spot items that the user failed to turn in. If you happen to be turning in someone else’s items, then after turning in the first of their items the table will display the list of items still issued to the other person helping to show you if they forgot to give you all of them.

Items that have the Multiple items with this same barcode number and Issue multiple of this item with single scan boxes checked as you see below may require a slightly different turn in process.

TCMax® must know whose items you are turning in.

  1. If you are turning your own items in and your username is on the screen, then TCMax® will default to turn yours in on the Multi-item screen.
  2. If you are turning in another user’s items, highlight the row for the user you are turning items in for and click either the Turn-In Selected button (if you need to turn-in items for multiple users) or the Turn-In and Close button (if you are turning items in for one user).
note

For companies using the wireless scanners with keypads on them (Datalogic Powerscan): The Multi-item screen will attempt to figure out whether you’re issuing or turning in this item. Depending on that decision when the screen opens, the cursor may be in the turn-in box or the issue box. Regardless of which box the cursor starts in, you can enter the plus sign + followed by a number to attempt to force TCMax® to issue more items out. Using a negative symbol – before the number will tell TCMax® you intend to turn items in. If the item is issued to more than one person, you will be asked to select the person whose items you’re turning in but using the + and – prefixes will prevent accidentally issuing or turning items in when you’re not looking at the screen. There is also an option in Settings > Options > General Options > Item Quantity Options to force the cursor to start in the same box each time.
