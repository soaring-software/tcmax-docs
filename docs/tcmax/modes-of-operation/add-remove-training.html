Add/Remove Training

The Add/Remove Training mode of operation allows you to assign training to individual users.

Example: if there is a new hire you can assign the specific training, they will need to perform their duties. Once assigned, you can access the Show Assigned Courses screen and that will display all users who have training assigned to them.

tip

You can create and edit courses in either the Training Completion mode or the Add/Remove Training mode. It is designed so that if you know how to create an item in TCMax® you will know how to create a course.

Setting Up Training Requirements​

Creating a Course​

In the Training Completion or Add/Remove Training mode, start by entering or scanning your desired Course Id and TCMax® will say “New Item”. On the right-hand side of the screen, you will be able to add additional details for this course, such as the Parent Course Id, Course Name, Course Number, and Course Interval (when the course will be due again). You will also be able to add details in the Curricula box and Part Numbers to certify Users on when the course is completed.

When setting up a Parent/Child relationship through courses, if you use the "Certify Part Numbers based on child course completion" checkbox, whomever is assigned the training will be assigned the child courses, not the parent course.

In order for a user to become certified on the part numbers used within the parent course, all children courses will need completed, not just one.

Creating a Child Course​

If this is a parent course that will have individual labs, lectures, or training sessions underneath them you can set this up by doing the following:

Step 1: Enter the individual training id into the main input box. TCMax® will say “New Item”.

Step 2: Enter the master training course number in the Parent Course Id box (this links this child to its parent course).

Step 3: Enter the name of this course in the Course Name box.

Step 4: If this course has a specific course number enter it into the Course Number box.

Step 5: In the Interval box, enter the number of days until the course will become due again. (Example: If it is a yearly training, you will enter 365) This will be used to set an expiration date on the certification of when the course will be due again to be certified again.

Step 6: Click Save

note

Courses aren’t required to have a master (parent) course.

Assigning a Training​

Step 1: Click on the Course User Defined Date menu option and select the date the training needs to be completed on from the date picker.

Step 2: Scan the Id of the User you need to assign training to, TCMax will say 'User'.

Step 3: Scan the Barcodes of the Training Courses that you would like to add for this user to later complete.

Step 4: TCMax® will say 'Added', this confirms that this User now has training assigned to them.

tip

You can scan or enter the Course Id in first, followed by each user to add users to a single course one after another or you can enter a user first and scan each course that you want to add for that user. If you want to assign a new course to a new person, hit the ESC key on your keyboard to clear the screen then you can bring up your next user and course in whichever order is most convenient.

If you need to view a Report that shows what courses are currently assigned and if/when they were completed, go to Reports > Training and select the desired Report(s).

When a User is diaplayed on the Main Screen before or after scanning a Course Id, the lower left will display courses that are assigned to the User. This allows you to view any courses the user has overdue, coming due, or newly added.

Removing a Training​

If you have assigned training to a user and they no longer need to receive it, you can easily remove it.

Step 1: Scan the Id of the user you need to remove training from. TCMax® will say 'User'.

Step 2: Scan the Barcode(s) of the Training Courses that need to be removed. TCMax® will say 'Removed'.

Show Assigned Courses​

If you need to see a list of what courses have been assigned to users, select Show Assigned Courses from the top menu bar.

If you use shifts and organizations, you can use the filters to filter by Shift or Organization. There are also filter options for Certification Shop Code and Certification Organization.

You can Add a User Filter to filter specific users out of the grid (When the grid has Enabled filter status selected), filter the grid for only specific users selected in the filter (When the grid has Reversed Filter Status selected). To ignore the filters, you can set your grid to a Disabled Filter Status to view all assigned courses.

Course Search​

To see a list of all courses, select Course Search on the top menu bar.

Use the search options to narrow down the grid and find specific courses.

You can also Print Barcode Labels for courses directly from Course Search by selecting the course, and with the course highlighted, select Print.

Editing a Course​

To edit a course, scan the Course Id on the Main Screen and select Edit.

You can also go to Course Search on the top menu bar.

Find your course and select the course you would like to edit then click "Display selected course on main screen"

You can edit multiple courses at one time in Course Search as well.

Go to Course Search and select File > Enable Editable Course Search (or press Ctrl + E on your keyboard).

When enabling editable course search, any column header highlighted in green is a field that can be edited or modified.

Once edits are complete you can Disable the Editable Course Search by unchecking the option in File > Enable Editable Item Search, or pressing Ctrl + E on your keyboard again.

You can also just close the Course Search without disabling the editable mode and all changes will still take effect.

note

The logged in user will need proper permissions to edit a course. If they do not, there will be no available option in the File menu to Enable Editable Item Search.

Course modifications are instant. There is no go back or undo button, so double check and verify you are modifying the correct course.

Deleting a Course​

To delete a course, go to Course Search on the top menu bar.

Select File > Enable Editable Course Search (or click Ctrl + E on your keyboard).

The column all the way to the left with no header will be highlighted green.

Search for and locate the course you would like to delete.

Select the column all the way to the left that has no header and this will highlight the entire row for the course.

Press DEL on your keyboard and the course will be instantly deleted.

note

The logged in user will need proper permissions to delete a course. If they do not, the column on the left with no header will not be highlighted green, and when trying to select the course and press DEL on the keyboard, no changes will appear.

Course deletions are instant. There is no go back or undo button, so double check and verify you are deleting the correct course.

Exiting Add/Remove Training Mode​

To exit Add/Remove Training mode, go to Mode= on the top menu bar and switch to the appropriate mode of operation.
