Resources

Existing User Data Migration Manual​

The Existing User Data Migration Manual menu option will direct you to our Version 8 to Version 9 Data Migration Guide. This Manual will assist in the migration process from TCMax® Version 8 to TCMax® Version 9.X.

Issue/Turn-In Instructions​

The Issue/Turn-In Instructions menu option outlines the issue and turn-in process for items in TCMax®.

Shortcuts (F1)​

The Shortcuts menu option will display different shortcuts/hotkeys that are available for use within TCMax®. The Shortcuts menu option can also be access by hitting F1 on your keyboard.

User Manual​

The User Manual menu option will direct you to our digital User Manual that contains different guides, instructions, and information regarding the TCMax® software.

About​

The About menu option will contain several important pieces of information regarding TCMax®. Provided below are the fields of what is displayed on the About menu.

Build Date​

The Build Date field signifies when the current installed Version of TCMax® was published.

Product Version and Database Version​

The Product Version field is used to identify the current installed Version of TCMax®.

The Database Version field is used to identify what Version of TCMax® your Database is upgraded to.

Licensed To​

The Licensed To field signifies the company/unit that the TCMax® installation is licensed to.

Support Id​

The Support Id field is an identifier for your company/unit. Often times when reaching out to our Customer Support Department you will be asked to provide your company/unit Support Id.

Status Code​

The Status Code field is used for internal purposes at Soaring Software Solutions, Inc.

Data Source​

The Data Source field is used to identify how your current TCMax® installation is connected.

Typically, if connected to a Stand-Alone, Local Database you will see the following information in your Data Source.

If connected to a Microsoft SQL Server® you will typically find a bunch of letters or numbers in your Data Source displaying the SQL Server Name.

Database​

The Database field is used to identify what TCMax® Database your installation is currently connected to.

Connected By​

The Connected By field is used to identify if your TCMax® Installation is connected by Windows Authentication or SQL Server Authentication.

Database Location​

The Database Location field is often only displayed if the Data Source is set to (localdb)\MSSQLLocalDB as the Database itself is stored locally. When connected to a Microsoft SQL Server®, you will not find a Database Location option as the Database is not stored on the local workstation.

Within the About menu, you will also see a Software License Agreement and a Run in Debug Mode option. The Run in Debug Mode option should only be changed when instructed by a Soaring Software Representative.

Visit TCMax Online​

The Visit TCMax Online menu option will direct you to our Soaring Software Solutions, Inc. website.
