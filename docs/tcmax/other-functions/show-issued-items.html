Show Issued Items

Selecting the Show Issued Items menu option from the Main Screen or pressing Ctrl + I on your keyboard will display a new screen of all the items that are currently issued out. There are several features from this screen that can help you manage and adjust the view of your issued items.

The Shop Code selection box located in the top right-hand corner will allow for you to limit this screen to a specific shop code, or allow you to look across all of your selected shops.

info

The Issued Items table can be sorted by clicking on any of the column headers and ordering the items either ascending or descending by the value of that column.

The Reports menu option located in the upper left-hand corner will allow for the user to generate various reports with the results that are displayed in the table.

tip

You can also right-click in the table at any time and send the displayed Data to an Excel spreadsheet.

The Help menu option located in the upper left-hand corner will contain descriptions on how the different filters are designed to work.

The Display on Main Screen button located in the lower right-hand corner will display the item you have selected from the table on the Main Screen.

The Show Issued Items screen can be filtered by the user(s) and/or location(s) an item is issued to or by the status of an item. These filters will appear in the Filtered Users or Filtered Locations/Status tables.

When the Filter is Enabled, the table will only display items that do not have one of the selected filters applied to them.

Filtering Users​

To filter out items issued to a User, select the Add User Filter button which will bring up a User Search window.

From the User Search window, you can search by the users Username or User Id. Once you’ve found the user(s) you want to filter by, double click on the user in the User Search List or Select the User then utilize the >> to move the user to the Selected Users table.

Hit OK on the User Search window and the user(s) you’ve selected to filter by will be in the Filtered Users list. You can quickly check and uncheck individual names in the filtered users list to enable/disable individual filters on the fly. You can also remove a user filter by clicking on the Username to select it and hitting 'Delete' on the keyboard.

Filtering Locations/Statuses​

The Filtered Locations/Status table can be customized to include any work location you would like.

To add a location / status filter, place the cursor into the text box above the Add Location Filter button and enter in the work location / status that you would like to filter by.

Once the information is input, click the Add Location Filter button and you will see the Location / Status added to the table. You can also remove the filter by clicking on it in the list and hitting the 'Delete' key on the keyboard.

Marking Items with a Status​

From the Show Issued Items menu option you can adjust / select different statuses for the items that are currently issued out. The statuses that are available from this menu option are Broken, Unserviceable, Lost, and Long Term.

To mark an item as Broken, Unserviceable, Lost, and Long Term, click in the appropriate row from the results table.

Then click the matching status button above the table to apply that status.

tip

While applying a status to an issued item, you can right-click the statuses (Broken, Lost, Unserviceable, Long Term) to add a log note and include any additional details about the occurrence.

info

An Item status filter will always override a location filter, so if you have an item that has a filter for both its status and location, the item will display as the color set for the status of the item (Lost, Broken, Unserviceable, Long Term).

Utilizing Filter Status​

The Filter Status button is a three stage button that allows you to adjust the view of your issued items. The Filter Status can be Enabled, Disabled, or Reversed.

info

By default all items that do not have a filter applied will be displayed.

Filter Status: Disabled​

The Disabled Filter Status displays all issued items regardless of their filters. You will still be able to distinguish the items that have a filters applied to them as they will continue to be highlighted in their filter color.

Filter Status: Reversed​

The Reversed Filter Status will display only the issued items that have a filter applied to them. This will allow you to disregard your non-filtered items.

Filter Status: Enabled​

The Enabled Filter Status will remove all items from the table that have a filter applied to them.

To exit out of the Show Issued Items screen click the Close button located in the bottom right corner of the screen or go to File > Close.
