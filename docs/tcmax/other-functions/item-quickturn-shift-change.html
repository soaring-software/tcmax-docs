Item QuickTurn @ Shift Change

This feature can be used during a shift change or to transfer the custody of issued items. You can enable/disable this option in: Settings > Options > Display Options > Show the “Item Quick Turn” menu. You may transfer items from a specific user or from a specific location.

Step 1: Select the Item QuickTurn @ Shift Change menu option located at the top of the TCMax® toolbar.

Once in Item QuickTurn @ Shift Change, scan, select, or enter a User Id / Location for the items in the Transfer Items From section.

All items issued to that user or location will appear in the table.

Step 2: Enter or Scan the User Id of the person to receive custody of the items in the box labeled Transfer Items To. You may also enter a new location for these items to be forwarded to.

tip

If a User is displayed on the Main Screen, the Issuing To: may already be filled out.

If a Location is entered on the Main screen, the Destination Location: may already be filled out.

Step 3 (Optional): By default, all items that are not restricted from transferring will be selected. Uncheck the Transfer checkbox located on the left side in the bottom grid to deselect any individual items you do not want to transfer to a different user.

There are also Check All and Uncheck All buttons in the upper right corner of the screen for ease of selecting / deselecting multiple items at once.

Step 4: Click the Transfer Checked Items button to perform the transfer of custody. TCMax® will play the “Transferred” audio prompt and return back to the Main Screen.

info

If a User and a Work Location are already displayed on the Main Screen of TCMax®, then that User and Location will be inherited as the Transfer Items To section.

tip

You can exclude certain part numbers from being able to be transferred by going to Tools > Catalog Setup and checking the Restrict Quick Turn box for the part numbers you wish to exclude.

note

If any of the items require certification and the User the items are to be transferred to is not certified for them, they will be highlighted in Red from the grid.

Hover over the highlighted item and a tool tip will display telling you what is preventing the transfer.

You can verify the change of custody by scanning or typing the User Id that these items were transferred to in the Main Input Box on the Main Screen or checking the Show Issued Items screen. That user will be displayed (if scanned) and the issued items grid in the lower left of the screen will show that they have custody of these transferred items.
