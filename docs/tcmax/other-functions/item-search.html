Item Search

Selecting the Item Search menu option from the Main Screen allows you to browse your entire inventory across one or more shops.

In the Item Search menu, you will notice drop-down boxes that allow you to filter down your results to an exact.

note

The search parameters are AND search boxes not OR search boxes, so the more Data that you enter, the more fine-tuned the search becomes.

Menu Options​

File​

The File menu option located in the upper left-hand corner will allow you to enter our Enable Editable Item Search mode or Close the Item Search screen.

Reports​

The Reports menu option located in the upper left-hand corner will allow for the user to generate various reports with the results that are displayed in the table.

Search Options​

Item Search gives the user several search options. These Search Options can be located from the upper left-hand corner of the Item Search screen.

Search Options > Look Across All Sites will include all sites and shops in its search results.

Search Options > Load Grid with Blank Search Criteria will display the first 5000 results without any search criteria and allow you to filter the results.

By default, when the Load Grid with Blank Search Criteria is left unchecked the Item Search screen will display zero results in the grid, because you haven’t searched for anything yet.

This is optional due to the potentially heavy load times on this screen with slower networks.

Search Options > Save Search Values will save your search criteria when you exit Item Search. This will allow your criteria from the last session to be present the next time this menu option is opened.

Export to Excel​

The Export to Excel menu option located in the upper left-hand corner will allow for the user to export the results that are displayed in the table to an Excel spreadsheet.

tip

You can also right-click in the table at any time and send the displayed Data to an Excel spreadsheet.

Help​

The Help menu option located in the upper left-hand corner will contain information on Search Filters, Color Legends, Grid Limit, and Viewing Items Issued to Multiple Users.

Utilizing the Search Parameters​

To utilize the Search Parameters in Item Search, enter text in any of the search fields and hit Tab or Enter. The grid below immediately displays any results that have matching text or checkbox values for that field.

Example: Entering Sock in the Item Name box causes the grid to immediately display any items that contain the letters Sock (wildcards are included in all search fields).

The Item Search screen also allows you to filter your search by Shop Code(s), Items issued to a specific User, or items issued to a specific Location.

Other Options within Item Search​

Display Selected Item on Main Screen​

If you want to display an Item on the Main screen, select the Item from the results grid then click the Display selected item on Main Screen button located in the lower right-hand corner of the Item Search screen.

The Item Search screen disappears and the Item is displayed on the Main Screen of TCMax®.

Print Item Label​

If you want to print an Item label, select the Item from the results grid then click on the Print Item Label button located in the upper right-hand corner of the Item Search screen. TCMax® will send the label to your selected Label Printer.

Total Items and Total Value​

The Total Items button will display the item totals based on what is displayed in the results grid.

info

The Total Items button will count the total quantity of items in your results, not the total number of barcodes (or unique items). Therefore, multi-quantity items will be counted as more than one single item if you have more than one of that item.

Example: If Barcode Id '701' is displayed which is a multi-quantity item (Screws) you will notice when selecting Total Items the total is 100 not 1.

The Total Value button will display the cost totals based on what is displayed in the results grid.

info

The Total Value button will count the total quantity cost of items in your results. Therefore, multi-quantity items will be counted as more than one single cost if you have more than one of that item.

Example: If Barcode Id '701' is displayed which is a multi-quantity item (Screws) you will notice when selecting Total Value my cost is $20.00 not $0.20.

note

Remember the Item Search screen is limited to the first 5000 results, so you may not see a correct total value or item count of your inventory.

Editable Item Search​

To enter the Editable Item Search mode, go to File > Enable Editable Item Search or press Ctrl + E on your keyboard.

note

TCMax® Users that do not have access to edit or delete items will not see this option in the File menu.

When in Editable Item Search, hitting the question mark in the far left-hand column will display the Editable Item Search information box.

Provided below will be an example of what the Item Search screen will look like when in Editable Item Search mode.

Editing Items​

If you have the user permission Allow Editing of Items then you will be allowed to edit Data from the Item Search screen.

To edit an items information, select the cell you wish to edit and begin typing to overwrite the old information in the cell. You can also double click into a cell to change or modify just part of the field.

tip

If you make any mistakes while editing, hit the Esc key on your keyboard before you change rows to cancel any unsaved changes. Once you change rows the Data has been changed and saved to the Database.

note

In version 9.10.0 and newer of TCMax®, date fields within Editable Item Search are treated as a text field, where a valid date must be entered.

Deleting Items​

If you have the user permission Allow Deleting of Items then you will be allowed to delete items from the Item Search screen.

To delete an item from the Item Search screen, highlight the row by clicking in the left-most column (this will highlight the whole row in blue) and hit the delete key on your keyboard.

warning

Before hitting the Delete key on your keyboard make sure that the highlighted row is the row you would like deleted as the change will be instant and permanent.
