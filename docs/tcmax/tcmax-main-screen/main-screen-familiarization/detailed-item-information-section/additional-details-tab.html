Additional Details Tab

The Additional Details tab allows you to document additional detailed information for your items. Some of these details will allow the item to appear on corresponding reports.

Notes​

The Notes field can be used to include any temporary item information and can be changed or deleted at any time. This field will also populate on the Comments section of the USAF MIL Report.

Item Type​

The Item Type dropdown box is where you categorize the type of item.

The Item Type will affect how the items are issued and turned in and will also affect how items appear on various reports throughout the software.

Item​

Item is the default Item Type in TCMax®. Most customers will enter most, if not all, of their items with this Item Type. For USAF customers, the Item Type must be set to Item for it to appear on the MIL reports.

Aerospace Coating​

An item marked as Aerospace Coating will require a weight to be entered when the item is issued and turned in, as well as a weight disposed value to be entered upon turn in. With this Item Type selected a Hazmat tab will appear where you can enter additional Hazmat information about the item. Disposable will be automatically checked under the Hazmat tab for any Aerospace Coating items.

info

You will not be able to uncheck the Disposable checkbox when an item is marked as Aerospace Coating. Each time you attempt to uncheck the Disposable checkbox, it will revert back.

Facility Keys​

An item marked as Facility Keys will require another person for turn-in purposes. When an item is marked as Item Type Facility Keys the person who took the key cannot be the one to turn it in.

Hazmat​

An item marked as Hazmat will require a weight to be entered when the item is issued and turned in. With this Item Type selected, a Hazmat tab will appear where you can enter additional Hazmat information about the item.

note

The Item Type Hazmat is designed to comply with US Navy Hazmat requirements. USAF customers are advised to enter Hazmat items under Item Type Item and use a custom checkbox to track their Hazmat items.

Hose​

An item marked as Hose will have a Hose tab available where you can enter addition information for the item. This Item Type is utilized by Fire Departments.

Rags​

An item marked as Rags will have special steps it undertakes when being turned in. Instead of being returned directly to stock they are first reissued to a dirty rags location and from there they would be sent to laundry. Once they have returned clean from laundry, they can be returned back to stock.

Manufacturer​

Manufacturer is the name of the manufacturer for the item.

Manufacturer P/N​

Manufacturer P/N is the Part Number the manufacturer uses for the item.

Date Received​

Date Received is the date when the item came into the Shop.

Contract Number​

Contract Number is the number of the contract for the item.

Mobility Increment​

Mobility Increment is the assigned or noted mobility increment of the item. This is mainly seen used in the Military.

Length​

Length is used identify the length of an item.

Width​

Width is used to identify the width of an item.

Height​

Height is used to identify the height of an item.

Weight​

Weight is used to identify the weight of an item.

CACRL​

The CACRL checkbox signifies the item is a Custodian Authorization / Custody Receipt Listing.

CACRL Value​

When CACRL is checked, this text field will appear. The CACRL Value is the value of the Custodian Authorization / Custody Receipt Listing.

Local Manufacture​

The Local Manufacture checkbox signifies the item is made by a local manufacturer.

Needs Chit for Issue​

The Needs Chit for Issue checkbox signifies the item will require a chit in order to be issued. This is mainly used by the Navy.

Password Required for Issue​

The Password Required for Issue checkbox signifies the item will require a password in order to be issued.

Precious Metal​

The Precious Metal checkbox signifies if the item is a precious metal.

Requires Charging​

The Requires Charging checkbox signifies the item will require charging upon turn-in.

Charge Duration (minutes)​

When the Requires Charging checkbox is checked, Charge Duration will appear. This is used to enter the number of minutes the item will need to charge in order to be fully charged. This will also prevent the item from being issued if the charge time is not completed from the previous turn-in.

Requires Control Number​

The Requires Control Number checkbox signifies the item will require a control number in order to be issued.

Shelf Life​

The Shelf Life checkbox signifies the item has a shelf life.

Spare​

The Spare checkbox signifies the item is a spare item.

Technical Order​

The Technical Order checkbox signifies the item is a technical order item.

TMDE​

The TMDE checkbox signifies the item is a Test, Measure, and Diagnostic Equipment item.

TMDE Value​

When the TMDE checkbox is checked, TMDE Value will appear. This is the item's Test, Measure, and Diagnostic Equipment's value.

Warranty​

The Warranty checkbox signifies the item has a Warranty.

Warranty Expiration​

When the Warranty checkbox is checked, the Warranty Expiration date field will appear. This is where the expiration date can be entered for the item's warranty.
