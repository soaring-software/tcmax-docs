Quantity and Status Tab

The Quantity and Status tab is where you set up each item’s quantity settings and can change the status of an item.

Quantity Settings​

Multiple Items with the Same Barcode Number​

The Multiple Items with the Same Barcode Number checkbox tells TCMax® that the scanned barcode represents more than one individual item.

Common examples for this type of item are bench stock (nuts, bolts, or screws) and/or Personal Protective Equipment (safety glasses, reflective vests, earplugs, or rubber gloves).

This setting can be used for items that are not individually tracked.

Issue Multiple Items with a Single Scan​

The Issue Multiple Items with a Single Scan checkbox signifies the item is a multi-quantity item and can have more than one quantity issued at a time. When attempting to issue items with this checkbox, TCMax® will prompt you and ask how many you want to issue or turn in. The software plays an “Enter Quantity” audio prompt and then presents an input box on the screen that asks you to enter the desired quantity.

Consumable Items​

The Consumable checkbox signifies the item is a consumable item within TCMax®. Basically, meaning that items can be used (consumed) on jobs and never returned, but until you tell TCMax® how many are consumed, the full quantity taken is expected to be returned. The software will ask for a consumed quantity if the quantity you are turning in is less than what was issued. TCMax® will adjust the quantities automatically for you based on what quantities have been entered.

Expendable Items​

The No Turn-In checkbox signifies an item is an Expendable item. In other words when this item is issued we are never expecting the item to be turned in. The quantities for these items will be immediately adjusted at the point of issue.

Expendable items are tracked independently of other items. In TCMax® there is a dedicated tab for Expendable items issued to a particular user as Expendables are not tracked via the regular issued items list or reports.

Qty on Hand​

Qty on Hand is the total quantity of the item in the Shop, including what is currently issued.

Qty Available​

Qty Available is the total quantity of the item on the shelf that can be issued.

Available by Part Number​

Available by Part Number will only appear if the item displayed has a Part Number assigned to it. This shows the quantity of the Part Number that is available / the quantity of the part number that is on hand.

By clicking on Available by Part Number, a grid will populate showing the items that have this part number, along with Quantity, Shop Code, Parent, Calibration Due Date, Storage Location, NSN, and Cost. (This grid can be right clicked on and sent to excel if needed)

Cost​

Cost is the monetary value associated with the item. This can be entered up to the 4th decimal place.

Vendor​

Vendor is the company that the item is acquired through. Only one vendor can be selected per Barcode Id (Item).

Do Not Reorder​

Do Not Reorder signifies this item is not to be reordered and will not populate on the Reorder Report. When an Item is marked as Do Not Reorder, TCMax® will not notify you if the item falls below the Reorder Qty, as the item is not to be reordered.

Max In Stock​

Max In Stock is the maximum allowed quantity for an item you want to stock at a time. This information will generate on the Reorder Report to help show when an item is ready for reorder and how many will need ordered to raise the item back to the max in stock value.

Reorder Qty​

Reorder Qty is the reorder threshold for multi-quantity items. When TCMax® falls below this specified quantity, it will appear in red signifying it is time to reorder. This is used as a means to prevent from completely running out of an item.

Qty In Unit​

Qty In Unit is the quantity of an item that is contained in each purchased/received unit.

Sold As​

Sold As is the description of how an item is purchased/ordered.

Example: Box, pallet, case, or each.

Status Settings​

Broken​

The Broken status checkbox is used to indicate any visual defects on an item.

note

Items marked Broken in TCMax® can still be issued.

Unserviceable​

The Unserviceable status checkbox renders the item unusable, and it cannot be issued.

Example: A screwdriver that has snapped into multiple pieces.

Deactivated​

The Deactivated status checkbox indicates an item is Deactivated and cannot be issued out. Often times this status is used for items past their usable lifecycle and are waiting to be replaced.

Lost​

The Lost status checkbox is used for items that cannot be located. This can be applied to items after they have been issued or during an inventory.
