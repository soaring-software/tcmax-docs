Kit Builder

The Kit Builder screen helps you to build, modify, and duplicate item kits or tool boxes.

To access Kit Builder, go to Tools > Kit Builder from the Main Screen of TCMax® or hit Ctrl + K.

The Kit Builder screen is divided into two main sections.

The left-hand side of the Kit Builder screen will provide a list of different functions that this screen provides.

The right-hand side of the Kit Builder screen will display the item/kit layout.

File Menu​

From the File menu, you can select any of the following three options, Add a New Item to the Selected Item/Kit, Print Labels for Selected Item/Kit, or Close.

Add a New Item to the Selected Item/Kit​

This option is used to add a new item to the kit (or you could utilize the F3 key on your keyboard).

Print Labels for Selected Item/Kit​

This option is used to generate labels for the selected item/kit (or you could utilize Ctrl + P on your keyboard).

Close​

This option is used to close the Kit Builder screen and return to the Main Screen of TCMax®.

Create/Display Kit to Build​

From the Create/Display Kit to Build section in Kit Builder you will need to select the Shop Code that your kit is or will be in.

Creating a New Kit​

To create a new kit, select the Create New Kit button.

This will bring up the Add New Item Record screen where you can enter the new kit's information. By default, the Barcode Id will pre-generate with your prefix and suffix that was set from Settings > Options > User and Item Barcodes or the Configure Barcode Format section in Kit Builder.

info

When adding a new kit, the Barcode Id must be unique within the selected Shop Code. If the value entered is already used by another item in the selected Shop Code, a red exclamation point will appear next to the Barcode Id field.

Once you have entered the Items information, press the Save button.

note

If you need to enter more information for an item than what is shown in the Add New Item Record screen, you will need to edit the item from the Main Screen of TCMax® or Item Search. In Kit Builder, the only information you can enter for a new item is the Barcode Id, Item Name, Storage Location, NSN, Part Number, and Serial Number.

Selecting an Already Existing Kit​

To add items to an already existing kit, type the item/kits Barcode Id into the Enter Kit Id text box, then select the Load Kit button.

Once the kit has been loaded, the item layout section will populate with the selected item’s layout.

Anything displayed in purple text from the item layout section will indicate the Storage Location that the particular item(s) lives within.

Adding Items to a New/Existing Kit​

Once you have created a new kit or selected an already existing kit an Enter Item Id section appears under the Create/Display Kit to Build section.

In the Enter Item Id textbox enter the Barcode Id of the item you would like to add/remove from the kit and then hit the Enter key on your keyboard or click the Add Item button on the screen.

Configure Barcode Format​

From the Configure Barcode Format section in Kit Builder, you can set the format of the Barcode Ids that TCMax® will assign to items when they are created or duplicated within Kit Builder.

In the Parent/Item group box, the barcode Prefix and Suffix can be set. The Prefix is a constant set of characters that start your Barcode; this Data can be alphanumeric. The Suffix is the set of numeric values that TCMax® will automatically increment as new items are created.

The Child Suffix can be set so that children of the kit are assigned a Barcode based on their Parent’s Barcode Id.

info

Both suffix values must be numeric as these fields auto increment.

Create New Item​

The Create New Item section will add new items to TCMax® and place them in the selected kit.

Selecting the Add New Item button will display the Add New Item Record prompt where you can fill in your new item's information.

Once you have filled out the new item’s information, press the Save button to add the item to the selected kit.

If you enter a new Storage Location when creating the item, you will see a new Location appear in purple text under the item layout section.

Duplicate Item(s) from Inventory​

The Duplicate Item(s) from Inventory section is used to duplicate items that already exist within your TCMax® inventory.

Within the Kit Builder screen, you can also duplicate items by right clicking them from the item layout section and selecting Duplicate Item.

Upon selecting Duplicate Item from the item layout section, you will be prompted with a Duplicate Item screen asking if you wish to duplicate this item inside or outside of the current kit.

If you chose to duplicate the item inside the kit, a Barcode Configuration screen will be displayed where you can enter the Times you wish to have this item duplicated, the Barcode Prefix, the Barcode Suffix, and the Child Suffix.

If you chose to duplicate the item outside the kit, a Shop Code List screen will be displayed asking which Shop Code you would like to duplicate the item(s) into. Upon selecting the Shop Code, you will be prompted with an Item Duplication screen asking if you would like to duplicate using the same barcode values, if not then you will be prompted with a Barcode Configuration screen.

From the Duplicate Item(s) from Inventory section, if you would like to keep the same Barcode Ids for the duplicated items then utilize the Keep the same barcode values from the selected items checkbox.

note

The Barcode values can only be kept if you are copying the item(s) to a different Shop Code as Barcode Ids must be unique across Shops.

To choose which item(s) will be duplicated, select the Search Inventory button.

You will notice an Item Search screen appears, this version of the Item Search screen is slightly different than the one accessed via the Main Screen of TCMax®, as it has functionality that will pass our selected items to the Kit Builder screen.

From the Item Search screen, you can highlight a row and add the item to your Selected Items grid by clicking the Add Selected Rows button or by double clicking the item you wish to add.

You can also use the Item Search functionality to limit the grid and then select the Add All Rows button to add all of the results in the search grid to the Selected Items grid.

If you select an item to duplicate that you did not mean to, you can remove it from the Selected Items grid. From the Selected Items grid, select the item you do not want duplicated and click delete on your keyboard. This will remove the item from the list, but not from TCMax® itself.

Once you have all the items you wish to duplicate added to the Selected Items grid, select the Finished button located in the bottom right-hand corner of the Item Search screen.

Upon selecting the Finished button, you will then be presented with a Barcode Configuration dialog box where you can confirm what Barcode Ids you would like assigned to the item(s), and how many times you want to duplicate the items(s).

Once you are satisfied with the Barcode Configuration, select Done. You will then see a Duplicated Items list where you can see what items will be duplicated and what their Barcode Ids will be.

Selecting Yes from the Duplicated Items list will duplicate the items.

Selecting No from the Duplicated Items list will cancel the duplication.

If Yes was selected, you will see a Duplication Successful popup appear indicating the duplication was successful. Press OK through the Duplication Successful popup to view your duplicated items in the kit layout.

If No was selected, you will be taken back to the Kit Builder screen.

Move Item(s) from Inventory​

The Move Item(s) from Inventory section is used to relocate items from your TCMax® inventory and place them in your selected item/kit.

To choose which item(s) will be moved, select the Search Inventory button.

You will notice an Item Search screen appears, this version of the Item Search screen is slightly different than the one accessed via the Main Screen of TCMax®, as it has functionality that will pass our selected items to the Kit Builder screen.

From the Item Search screen, you can highlight a row and add the item to your Selected Items grid by clicking the Add Selected Rows button or by double clicking the item you wish to add.

You can also use the Item Search functionality to limit the grid and then select the Add All Rows button to add all of the results in the search grid to the Selected Items grid.

If you select an item to relocate that you did not mean to, you can remove it from the Selected Items grid. From the Selected Items grid, select the item you do not want relocate and click delete on your keyboard. This will remove the item from the list, but not from TCMax® itself.

Once you have all the items you wish to relocate added to the Selected Items grid, select the Finished button located in the bottom right-hand corner of the Item Search screen.

Upon selecting the Finished button, you will then be presented with a Relocated Items list where you can see what items will be relocated.

note

If the item(s) you selected already live within a kit then you will be prompted with a Child Item(s) screen. This will indicate if you continue with this selection that the item will be removed from the original kit and added to the selected item/kit.

Selecting Yes from the Child Item(s) screen will move the item(s) to the selected kit.

Selecting Yes from the Relocated Items list will relocate the item(s).

Selecting No from the Relocated Items list will cancel the relocation.

If Yes was selected, you will see a Relocation Successful popup appear indicating the relocation was successful. Press OK through the Relocation Successful popup to view your relocated items in the kit layout.

If No was selected, you will be taken back to the Kit Builder screen.

Removing Items from a Kit​

From Kit Builder, there is two options on removing items from kit.

Option 1​

To remove items from a kit, right click on the item to be removed from the kit layout section and select Remove Item from Parent.

Option 2​

To remove items from a kit, drag and drop the selected item to the tool-box icon located in the bottom right-hand corner of the kit layout screen.

info

By removing an item, you are not deleting the item from TCMax®. The item being removed will still exist in the Database, it will just no longer be a child of the parent and have no relationship to that parent.

View Selected Item Details​

The View Selected Item Details section is used to show you the details of the item you have selected from the kit layout section of Kit Builder. The only information that can be adjusted from this section is the item’s Storage Location.

Adjust the Kit Layout​

The Kit Builder has a drag and drop feature to easily move or adjust the layout of the kit. From the Kit Layout, you can click and drag an item to a new storage location to relocate that item within the kit. You can also click and drag an item into another item to create a separate parent-child relationship and create a grandchild of the overall kit. TCMax® offers a drag and drop for ease of use when viewing and changing the layout of a kit.
