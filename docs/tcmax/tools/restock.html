Restock

The Restock feature allows you to restock items with like Part Numbers when your quantities fall below set values.

Before using the Restock functionality, there are few key points you must be aware of:

  1. The item to be restocked must have a Max in Stock value set for that item. This value is needed as it is how TCMax® knows how many items are needed to restock the item to par value.
  2. Items marked as spares are given a higher restock priority than items not marked as spares.

Items may need to be restocked because they are consumable/expendable items that have been issued and their quantity on hand has fallen below the Max in Stock value or the item quantity was found to be deficient during a physical inventory.

To use the restock functionality, go to Tools > Restock or press Ctrl + Shift + R on your keyboard to open the Item Restock screen.

Load from Stock​

Selecting the Stock button will bring up a dialog box where you can load an item directly from your stock.

You need to specify the Shop Code the item to be restocked is in and enter its Barcode Id into the Enter Barcode Id entry box. If you hit the Enter key some of the important item’s details will be displayed on this dialog box. You can also specify the Shop from which you will pull the item from.

Once your Data has been entered, you can click the Select button and the Item Restock screen will display the item you selected.

Your results will appear as either green, yellow, or red. When you expand the details for an item you will see a breakdown of the item you are restocking (left) and the stock you are pulling from (right).

Green indicates that not only has a match been found but the stock you are pulling from has a sufficient available quantity to top off the item to its max in stock value.

Yellow indicates that a match has been found but the quantity available is not enough to fulfill the max in stock threshold for the item.

Red indicates that either no match has been found or there is no available quantity to pull from.

At this point you can either manually enter information to pull stock from or correct any identified discrepancies.

The lookup button will allow you to query the Item Search screen to locate an item on several parameters.

Once you are satisfied with the results and everything looks good you can select the Accept button to transfer the available stock into the destination stock, properly updating quantities and creating corresponding log records.

info

If more than one match has been found then the corresponding Shop Code and Barcode Id dropdown box will allow you to change where you are restocking from.

TIP: You can restock an entire kit by entering the Parent Barcode Id and pulling several items at once.

TIP: Pay attention to the icon in the lower right corner of the results. If there is a discrepancy, then a tooltip will be displayed upon hovering over this icon for details.

Load from Previous Inventories​

The restock screen can also populate Data based off shortages discovered during Physical Inventories. To load the screen based on this information click the Previous Inventories button.

You will then need to select the kit containing the items you would like to restock by selecting it from the Select a kit dropdown menu. You can optionally select the Shop which the stock will be pulled from. Once you have made your choices, click the Select button.

Once you have matched the items you would like to restock with the stock that they will pull from, the Accept button can be clicked to make the changes in TCMax®.

When you click the Accept button, you will be asked if you would like to perform the restock automatically.

Clicking Yes will remove the items from spare stock and replenish the items being restocked.

Inventory Restock​

Clicking No will remove the items from spare stock but will not replenish the items being restocked. You will have to go back into the Inventory Selection screen to complete the restock process.

To do an Inventory Restock you will then need to navigate to Tools > Inventory and then click the Restock button.

A Physical Inventory Setup dialog will open where you can choose the kit that contains the items you need to restock.

Highlight the kit you want to restock and click Perform Restock. This will open a modified Inventory screen with the items that need restocked listed, so you can inventory the items as they are replenished.

To restock your items, you can scan, tap, or double click the listed item or single click it and adjust the Inventoried Quantity. Finally, Select the Complete Inventory button in the bottom right corner of the screen to complete the process.

Receipts​

If you checked the option to Check to print receipts, two receipts will be generated. One will include the list of items that need restocked and the other is a list of items to pull from spares to restock those items.
