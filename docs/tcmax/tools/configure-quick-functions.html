Configure Quick Functions

Quick Functions are used to perform various actions within TCMax® by scanning a structured barcode to automate a process and quickly perform tasks on the fly. Utilizing these barcodes saves the end user from having to navigate around the Main Screen.

Setting Up Quick Functions​

To access the setup screen, navigate to Tools > Configure Quick Functions from the Main Screen.

From the Configure Quick Functions screen, expand the node for the action that you wish to set up a barcode for. The sections are labeled according to the name of the action that they will perform.

For example, if you want to create a structured barcode that will mark an item as broken, you’d expand the Broken node and click the plus sign to create the new preset configuration.

Quick Function Categories​

Broken, Unserviceable, and Deactivated​

The Broken, Unserviceable, and Deactivated functions behave similarly with the exception that one will mark the item as Broken, one will mark it as Unserviceable, and the other will mark it as Deactivated.

This Transfer function will allow you to create a barcode that will transfer the item on the Main Screen into a different shop.

Arrival / Departure​

The Arrival / Departure function allows you to create either an Arrival or Departure barcode to track where your Users are. When scanning this barcode it will keep track of where Users are or are going.

Arrival / Departure Subcategories​

When first Selecting the + to add an Arrival / Departure, you will be prompted for a Location to Set for the barcode. This is the Location you will want displayed when this barcode is Scanned.

Name is the description that will print with the barcode when you generate the physical label.

Type is the type of barcode that is being created. You have the choice of Arrival or Departure to show what the User is doing at this Location.

The Prompt for next destination checkbox will only be active when selecting Departure. When scanning this barcode for a Departure, you can have TCMax prompt for the next destination to be entered.

Audio File will allow you to select any wave file to be played when this Quick Function is scanned. When clicking Audio File, a File Explorer screen will open for you to point TCMax® to and select your wave file to be played.

User Certification Revoking​

The User Certification Revoking function allows you to revoke a User's Certification temporarily for Items based on a Course, Part Number, or a List of selected Part Numbers. This Quick Function Barcode will be used when a User is on the Main Screen.

User Certification Revoking Subcategories​

Name is the description that will print with the barcode when you generate the physical label.

Revoke Type is how you will Revoke a User temporarily. If you Revoke based off a Course, Part Number, or Part Number List. Once you select your Revoke Type click the Set button and you will be prompted for a Course Barcode Id, a Part Number, or to select a Part Number List that is pre-created in Revoke List Setup.

Expires In (Days) allows you to set a Number of Days you would like the Revoking to Expire and the User to become Certified again.

info

If you leave this at 0, the certification will remain revoked until an Un-Revoke Barcode is Scanned.

The Revoking: Open log note Screen checkbox will open a Log Notes Screen when scanning the Quick Function Barcode. This can allow you to add details to the Log Notes about why a User is being Revoked or Unrevoked.

Print Revoke will print the barcode for Revoking Users Certifications. This can be placed by the computer for quick use when needed.

Print Unrevoke will print the barcode for Un-revoking (Or Re-Establishing) Users Certifications. This can be placed by the computer for quick use when needed.

Presets allow you to include additional settings in the quick function that wouldn't otherwise fit into the physical barcode label. The Full Value will work without the need to set this up in the Quick Function Configuration. Presets also have the ability to work without a scanner if you do not have one.

Setting up a Part Number List for Revoking Certifications​

Go to Settings > Revoke List Setup from the Configure Quick Functions screen. Once on the Revoke List Setup screen, you will need to give a name for the list you are creating. To do this, click the Add New button and type the name for this list. Then, enter the Part Numbers/Barcode Ids that this revocation pertains to and click the Submit button. Those items will be added to the grid on the right. When you are done adding, click the Close button.

Now that the list has been generated, you will be able to apply it to your preset.

Under the ‘User Certification Revoking’ node, click the Part Number List radio button, and then click the Set button. From the ‘Revoke List’ screen, click the appropriate pre-configured list and click Select.

Using Structured Barcodes​

Structured Barcodes are intended to be scanned while there is a user or item displayed on the Main Screen of TCMax®. They can also be stacked together to perform multiple operations at once.

For example, if we wanted to mark our battery as broken and then transfer it to a manufacturer for warranty replacement, you could set up a preset for marking it as broken and then set up a preset for transferring it to a specific shop. Each individual preset barcode would decode into the following strings:

<B pSet='1'/>: This tells TCMax® to run through the Preset 1 code for a Broken structured barcode.

<TR pSet='1'/>: This tells TCMax® to run through the Preset 1 code for a Transfer structured barcode.

If you encode your barcode with both values, TCMax® will run through both procedures in the order they appear. So, if your barcode decodes into <B pSet='1'/><TR pSet='1'/>, the software will follow the Broken Preset 1 input and then immediately go through Transfer Preset 1.
