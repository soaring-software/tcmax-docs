Maintenance Procedure/Bulk Issue Setup

Maintenance Procedures​

A Maintenance Procedure is a specific task within an organization that requires a certain set of items and/or equipment to perform. From the Main Screen, you can scan or type a Maintenance Procedure barcode number into the input box and TCMax® will print a complete list of the items and/or equipment required for this procedure, where they are stored, and who is currently using them.

Utilizing Maintenance Procedures​

Maintenance Procedures will be setup and managed through the Setup Maintenance Procedures / Bulk Issues screen.

To access this screen, select Tools > Maintenance Procedure / Bulk Issue Setup.

Creating Maintenance Procedures​

To create a new Maintenance Procedure, select the Add New Maintenance Procedure button and enter in the procedure’s information. Once all Data is entered, press the Save button to create the Maintenance Procedure.

Selecting a Maintenance Procedure​

From the Maintenance Procedure screen, refer to the Select Maintenance Procedure section and utilize the drop down to select a Maintenance Procedure.

Viewing Items that are Assigned to a Maintenance Procedure​

Once you have selected a Maintenance Procedure, a table will display with the items and/or equipment that have been added to the selected procedure.

Adding Items to a Maintenance Procedure​

To add items to a Maintenance Procedure, refer to the Add Item to Maintenance Procedure box then enter/scan the Part Number/Barcode Id of the item you wish to add.

note

The item in which you are adding must have a Part Number assigned.

Upon entering/scanning the Part Number/Barcode Id, the table will display the Quantity and Part Number of the Item you added.

For multi-quantity items, click in the Quantity column, enter the desired amount, and hit Enter.

info

When adding items to a Maintenance Procedure, you will notice the Part Number is what appears in the details for each item. Therefore, if you require two items with the same Part Number, you will need to increase your quantity of the Part Number.

Deleting Items from a Maintenance Procedure​

To remove an item from a Maintenance Procedure, select the item from the table to highlight the entire row then press the Delete key on your keyboard.

Upon hitting Delete, the item will be removed from the table.

Deleting Maintenance Procedures​

To delete a Maintenance Procedure, select the Procedure you wish to delete then press the Delete button from the Setup Maintenance Procedures / Bulk Issues screen.

A confirmation window will appear asking if you are sure you want to continue with the Delete. Press Yes.

Upon hitting Yes, the Maintenance Procedure will be removed.

Bulk Issues​

Bulk Issues are designed to issue several items (usually expendables) with a single scan. This works similar to items in a kit (toolbox) but does not require the items to be within the same kit.

note

If you are issuing multiple items using a bulk issue that will need turned in, these items will have to be turned in individually. Bulk Issue will issue the items out in bulk with a single scan but will not return the items with a single scan. They would need returned individually.

Utilizing Bulk Issues​

To access this screen, select Tools > Maintenance Procedure / Bulk Issue Setup.

Once on the Setup Maintenance Procedures / Bulk Issues screen, select the Bulk Issues tab located at the bottom of the screen.

Creating Bulk Issues​

To create a Bulk Issue, select the Add New Bulk Issue button and enter in the bulk issue information. Once all Data is entered, press the Save button to create the Bulk Issue.

Selecting a Bulk Issue​

From the Bulk Issue screen, refer to the Select Bulk Issue section and utilize the drop down to select a Bulk Issue.

Viewing Items that are Assigned to a Bulk Issue​

Once you have selected a Bulk Issue, a table will display with the items that have been added to the selected Bulk Issue.

Adding Items to a Bulk Issue​

To add items to a Bulk Issue, refer to the Add Item to Bulk Issue box then enter/scan the Barcode Id of the item you wish to add.

Upon entering/scanning the Barcode Id, the table will display the Quantity, Barcode Id, and Item Name of the Item you added.

For multi-quantity items, click in the Quantity column, enter the desired amount, and hit Enter.

Deleting Items from a Bulk Issue​

To remove an item from a Bulk Issue, select the item from the table to highlight the entire row then press the Delete key on your keyboard.

Upon hitting Delete, the item will be removed from the table.

Deleting Bulk Issues​

To delete a Bulk Issue, select the Bulk Issue you wish to delete then press the Delete button from the Setup Maintenance Procedures / Bulk Issues screen.

A confirmation window will appear asking if you are sure you want to continue with the Delete. Press Yes.

Upon hitting Yes, the Bulk Issue will be removed.
