Physical Inventory

Utilizing Physical Inventory​

Physical Inventory is used to inventory a specific kit or collection of items that are associated by parent/child relationships.

To access the Physical Inventory menu, select Tools > Inventory > Physical Inventory or press Ctrl + Shift + I on your keyboard then press Physical Inventory.

Upon selecting Physical Inventory, the Physical Inventory Setup screen will appear. The Setup screen allows you to set up how you would like the Physical Inventory to be ran.

From the Physical Inventory Setup screen you will see four different steps. These steps will need information entered into them before you can proceed with the Inventory session.

In Step 1, you will select the type of inventory to be performed. Your options are either Full or Partial.

A Full Physical Inventory will inventory the kit, its children, and sub-kits (depending on the settings in Step 2).

A Partial Physical Inventory is used to inventory a specific sub-kit or storage location within a kit.

Step 2 allows you to decide how many generations of the kit you would like to include in the inventory session.

To set the generation that you would like to include in the inventory session, move the slider arrow up or down until the generation limit you want is selected.

All will include all generations of the kit. Great Grandchildren will inventory three generations of the main kit. Grandchildren will inventory two generations of the main kit. Children will inventory one generation of the main kit.

In Step 3, select the Shop Code in which your kit exists in from the drop-down menu.

note

You can only inventory kits from one Shop Code at a time.

In Step 4, scan or enter the Barcode Id of the kit to be inventoried.

Conducting a Physical Inventory​

At any point during the Physical Inventory, if you need to leave the screen to perform other tasks, you can select Close in the bottom right-hand corner of the inventory screen. Upon selecting Close, your inventory session will be paused giving you the option to pick up where you left off when returning to the Physical Inventory Setup screen.

If you started an inventory session and did not complete it before leaving the Inventory mode, you can complete the inventory by selecting the Join Existing Inventory tab, highlighting the inventory you wish to complete, and clicking the Join Selected Inventory button.

If all your Physical Inventories have been completed and you do not have one that is waiting to be completed, you will not see this tab. The Join Existing Inventory tab only appears when there is an inventory that was started and not completed.

If you selected Full Inventory in Step 1, the Physical Inventory screen will open.

If you had selected Partial > Kits or Storage Locations, a selection window will open asking you what sub-kit(s) you would like to perform the inventory for.

You can select the sub-kit(s) or locations then select the Start button to begin the Physical Inventory for the selected items.

The Physical Inventory screen has been optimized to work on both tablet and desktop PCs. You can inventory an item by either double clicking (tapping for touch-enabled devices) on the item in the list or by scanning the item’s Barcode Id. In either case, inventorying the item will place a green checkmark next to the item indicating that it has been inventoried during this session.

If you are using a barcode scanner and interact with an item that has been set up as a multiple quantity item, you can enter the quantity for that item in the upper right-hand corner of the screen.

The expected quantity will be listed in the Item Details section. If the inventoried quantity matches the expected quantity the item will be marked as inventoried with a green check mark. If the Expected Quantity and Inventoried Quantity don’t match, it will be recorded as having been inventoried with a discrepancy.

If "Auto inventory children when parent is scanned" is enabled, through the Options Menu, the system can automatically inventory the children, speeding up the inventory process. When enabled, the user can simply scan/select a parent to inventory all of its components. This feature works for any smaller, sub-kits/item groups that are part of the larger kit (Example - A set of sockets that are stored in a larger tool box).

If you inventory an item in error, you can right click on the item and select Reset from the menu that appears.

This will reset the item as if it had not been inventoried.

Updating Inspections During Inventories​

For items with inspections, the item will be red for required/overdue inspections or orange for imminent inspections. There will also be an Inspections group box that appears on the right side of the screen when you select the item. If the item is underlined, then it has an Inventory Inspection loaded against it that must be updated to complete the inventory.

To update the inspection, click on it then select the Complete button.

Applying Conditions​

During the inventory process, you can apply Conditions to items.

The conditions that are available during the Physical Inventory process are Excellent (E), Good (G), Fair (F), Poor (P), and None (N).

Before an item is inventoried, select the button for the condition you would like to apply from the top of the Inventory screen.

Once the condition has been selected, scan, type, or double-click on the Barcode Id that you wish to inventory.

Upon inventorying the Barcode Id, the item will be Inventoried and display with a green checkmark and the condition that was applied.

Applying Statuses​

During the inventory process, you can apply Statuses to items.

info

Versions 9.8.9329.21809 or older will not have the ability to apply Statuses to an item within the Inventory Session.

The statuses that are available during the Physical Inventory process are Broken, Unserviceable, Deactivated, and Lost.

To apply a status to an item that has been inventoried or has not been inventoried, select the item you would like to apply the status to from the Items list then select the status you would like applied.

Once the status has been applied, we will mark that item with the selected status within TCMax® and write corresponding log records.

Discrepancies​

Discrepancies are inconsistencies with items that have been discovered/entered during the inventory process.

Quantity Did Not Match: This discrepancy is generated during Physical Inventory when the Inventoried Quantity does not match the Expected Quantity.

Generic: This discrepancy is generated during Physical Inventory when you right click on the item and select Add Generic Discrepancy.

Upon selecting Add Generic Discrepancy, a Discrepancy Note entry screen will appear where you can enter information about the discovered discrepancy.

A red x will then appear in the inventory status button for that item.

A Discrepancy can be resolved before completing the inventory by clicking on the Discrepancy and selecting the Resolve button. Once you have selected the Resolve button, you will then get a Resolve Discrepancy entry screen which allows you to update the discrepancy’s note.

Selecting the Accept button will accept the resolution. The Discrepancy will then be marked as resolved in the Discrepancy List. The item will then be updated with a green checkmark instead of a red X in the inventory status.

Does Not Belong in this Inventory: This discrepancy is generated when an item that is not listed as being part of the kit is inventoried.

Not Inventoried: This discrepancy is one that cannot be manually added to an item. The discrepancy is generated when you did not inventory items before selecting the Complete Inventory button. This discrepancy cannot be resolved other than re-inventorying the kit and making sure all items are accounted for.

Notes​

Inventory Notes can be added to items during the Physical Inventory process by highlighting an item and clicking the Add/Edit Note button on the right side of the screen or by right clicking on the item and selecting Add/Edit Note.

These Notes are added to the log records and kept for reporting purposes.

Remove from Kit​

If, during the Physical Inventory Session, you have discovered an item that does not belong in the kit, you can remove the item from the selected kit. This function can be accessed by right clicking on the item in question and selecting Remove From Kit.

Completing the Physical Inventory​

To complete the Physical Inventory and commit the records to your Database, click the Complete Inventory button in the bottom right-hand corner of the Inventory screen.

If any items have been missed from being inventoried, an Items Not Inventoried popup will appear letting you know not all items have been accounted for. You can then choose Yes to complete the inventory anyways, which will create Discrepancies for any item that has not been inventoried, or choose No to go back and inventory any item that was missed.
