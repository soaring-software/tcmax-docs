User Profile Setup

User Profiles are beneficial when making bulk edits to multiple users and to limit access to the user options screen.

Utilizing User Profile Setup​

To access User Profile Setup, select Settings > User Profile Setup from the Main Screen of TCMax®.

Creating Profiles​

To create a user profile, select Create New Profile from the User Profile drop down.

Once you select Create New Profile, a message box will ask for the name of the profile in which you are adding.

Enter the new profile name, then press OK. The user profile will be added to the User Profiles section.

Assigning Profiles a Password/Permissions​

Once a Profile has been added/selected, refer to the bottom half of the User Profile Setup screen.

From the bottom half of the User Profile Setup screen, select the permissions you wish for this profile to have.

When the desired permissions for the profile have been selected, refer to the Default Password section located in the upper right-hand corner of the User Profile Setup screen.

info

A password is only required if you intend on users under this profile to be able to login to TCMax®.

Enter the desired password for the User Profile. Once the password has been entered, re-enter the password into the confirm password field. If the passwords match you should see green text that states 'Match'.

Once you receive 'Match', press enter again to set the password to the User Profile. Upon doing so, you should see text that states 'Password Is Set'.

After permissions and a password have been assigned, click the Save button.

note

Checking the option Default User Profile will automatically cause all new users added to TCMax® to inherit the profile permissions.

Deleting Profiles​

To delete a user profile, use the drop-down menu to select the Profile you would like to delete.

With the Profile selected from the drop-down menu, select Delete.

You will receive a popup stating 'Continue? Deleting this profile will also set all users tied to this back to their standard permission.' Select OK to delete the profile.

Once you have selected OK to delete the profile, you will notice the profile has been removed from your drop-down list. Select SAVE in the bottom right corner of the User Profile Setup screen to save the changes.

Assigning Profiles to Users​

Once Profiles have been created, they can be assigned to Users from Settings > User Options or the Main Screen of TCMax®.

Option 1​

From the Main Screen of TCMax®, select Settings > User Options.

From the User Options screen, select a user and choose the desired profile from the Current Profile dropdown.

Once the User Profile has been assigned, select the Save button located in the lower right-hand corner of the User Options screen.

Option 2​

From the Main Screen of TCMax®, display a User you want to add a profile to.

When a user is displayed on the Main Screen, a blue edit button will appear above their name.

Select the edit button to display the user details screen.

This screen will allow you to assign a specific profile from the drop-down list.

After selecting the User Profile, click the Update User button. When clicking the Update User button, a login screen will appear to assign an individual to a profile. The credentials entered on the login screen must be for a user who has the same or more permissions, including the permission Allow Profile Assignment Outside of User Options.

If you are unsure which users can elevate the selected user to the desired profile, click the Display Users With These Permissions hyperlink to view eligible user logins.

note

When a user is under a User Profile the permissions set up for that Profile will override the permissions set up for that user in User Options.
