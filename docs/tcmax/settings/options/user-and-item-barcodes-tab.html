User and Item Barcodes Tab

The User and Item Barcodes tab tells TCMax® how to process scanned inputs and how to decide whether you are entering an Item Barcode or a User Id.

Barcode Id Configuration​

From the Barcode Id Configuration section, you will see Primary and Secondary Prefix and Suffix values. The Primary and Secondary Prefix and Suffix are used as a shortcut on the Main Screen to create new item Barcode Ids with a single keystroke. TCMax® will use these values to find the next available Barcode Id, keeping the newly created items in sequential order.

The Prefix value can be alpha/numeric. The Suffix value must be numeric only.

info

The Suffix is how TCMax® will increment to find the next available Barcode Id, TCMax® cannot increment alpha characters.

Once a Primary or Secondary Prefix and Suffix is set, the hot keys to create an item on the Main Screen can be utilized. The F3 key can now be utilized to create a new item from the Primary Prefix and next available Primary Suffix. The Ctrl + F3 key can now be utilized to create a new item from the Secondary Prefix and next available Secondary Suffix.

Partial barcodes can be generated as well by hitting the F9 key from the Main Screen. TCMax® places the Prefix from the Primary barcode sequence in the Main Input box so you can type your own Suffix. Hitting Ctrl + F9 adds the Prefix from the Secondary barcode sequence.

Example Scenarios of Barcode Id Configuration​

If you want your item Barcode Ids to be all numeric then leave the Prefix box blank.

If you want your Barcodes to be six digits long but want to start with the number one thousand, then you should enter 001000 in the Suffix box.

If you want to use three-digit Barcodes and want to start with the Barcode Id one, then you should enter 001 in the Suffix box.

User Id Configuration​

The User Id Configuration section will provide options on how to specify how users will be distinguished in TCMax®. The User Id Configuration section will provide four different barcode lengths, prefix and suffix values, along with additional configuration settings that can be selected.

User Id Length 1, User Id Length 2, User Id Length 3, User Id Length 4​

User Id Lengths 1-4 are the four different barcode length values that can be filled in to identify the character count of your users. If no additional configuration settings are configured in the User Id Configuration section, this method will be used by default.

The number of characters in the User Id must be different than your items in TCMax®. When utilizing User Id Lengths 1-4, when anything is scanned, TCMax® counts the characters. If the length matches any of the numbers in these four boxes, then TCMax® treats it is a user. Anything else will be considered an item.

note

To only use some of the pre-defined lengths, zero (0) out the remaining fields.

For example, if you only want to recognize two-character User Ids then zero (0) out lengths 2 through 4.

Use first 15 digits of Id card only, U.S. Military​

This option is used when you use U.S. Military Id cards and have a 2-D barcode scanner. It makes both front and back barcodes read the same value.

If you check this box, make sure one of the User Id Length values equal 15.

Use 2 – 15 digits of Id card only​

This option is used when you use U.S. Military Id cards and the first character on the front and back are different. With this option selected, TCMax® will skip the first character and move on to the second character.

If you check this box, make sure one of the User Id Length values equal 15.

Any Barcode Starting with the User Prefix will be Treated as a User​

This option is used when User Ids begin with the same character(s). When this option is enabled, enter the Prefix your User Ids begin with in the Prefix box. When a user barcode is scanned that begins with the Prefix, TCMax® will treat that barcode as a user, no matter the length of characters.

Differentiate Item/User Based on Leading Character​

Differentiate Item/User Based on Leading Character allows you to tell TCMax® the first character style of all users and items.

Checking the top box, First character Alpha = User,Numeric = Item, recognizes anything scanned that's first character is a letter between 'A' to 'Z' as a user. Anything beginning with a number between zero and nine is recognized as an item.

Checking the bottom box, First character Numeric = User,Alpha = Item, recognizes anything scanned that’s first character is a number between zero and nine as a user. Anything beginning with ‘A’ to ‘Z’ is recognized as an item.

info

The User Id length counts 1-4 will no longer matter when using one of these options, as TCMax® will determine if the entered value is a user or item based on the leading character.

Check Barcode Length​

To check the number of characters in any barcode, click in the box at the bottom of the User and Item Barcodes tab and scan the barcode. Once the barcode has been scanned, the character count will appear to the right in the textbox along with how TCMax® currently recognizes that barcode (item or user).
