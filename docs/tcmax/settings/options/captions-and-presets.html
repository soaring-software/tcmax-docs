Captions and Presets Tab

The Captions and Presets tab will provide different captions that can be customized along with different preset options that can be selected and customized.

Custom Captions​

From the Captions and Presets tab, you will have the capability to customize the default captions in TCMax®. The captions can be changed by editing what you see in the text box next to the caption, once those changes have been made, they will then be displayed throughout the software upon save.

Not all captions in TCMax® can be customized, but a wide variety can be customized.

Provided below will contain the different field captions that can be modified.

info

Changing the caption will not change the functionality of the field; it will only change how that caption is displayed.

Preset Options​

TCMax® has several preconfigured option sets that have been developed over years of interactions with our customers. The preset buttons, when clicked, will apply the options and captions set that we have found to be the most standard amongst specific types of installations.

Custom Option Presets​

As the options and captions in TCMax® are stored and referenced on your local machine, if you would like to save your captions and options for later or for easier Deployment across multiple machines you can load, create, delete, and save your custom presets by using the corresponding buttons.

info

Presets can be automatically loaded against specific Shop Codes to maintain standardization on server hosted Databases by configuring Auto Load Presets.
