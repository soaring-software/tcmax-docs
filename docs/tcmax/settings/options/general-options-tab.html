General Options Tab

Calibration and Inspection Options​

Ask for Date Calibration or Inspection was Actually Performed for Reports​

When performing inspection and calibration updates, instead of using the current date, the User is asked for the date the inspection or calibration was performed. Often times this option is utilized to backlog when the inspection or calibration was completed.

Do Not Check Grandchildren for Overdue Calibrations and Inspections​

TCMax® will restrict the issuing of items that have overdue inspections or calibrations to the parent and children items only, allowing grandchildren with an overdue inspection or calibration to be issued.

Set Lead Time for Calibration Warning​

When interacting with an item that has a calibration, you can specify when you want TCMax® to warn you with an audible and visual warning for imminent calibrations that are not overdue but coming due.

Set Lead Time for Inspection Warning​

When interacting with an item that has an inspection, you can specify when you want TCMax® to warn you with an audible and visual warning for imminent inspections that are not overdue but coming due.

Course Options​

Ask for Date Expired When Course Interval is 0​

When a course interval is set to 0, TCMax® will ask for the expiration date each time the course is completed. This is used if you want different expiration dates.

Set Lead Time for Imminent Courses​

When interacting with courses that are assigned to users, you can specify when you want TCMax® to warn you with a visual warning for imminent courses that are not overdue but coming due.

Dashboard Options​

Disable Dashboard​

The Dashboard panel will not open when clicking the blue line on the Main Screen.

Display Dashboard on Startup​

The Dashboard panel will appear by default upon launching TCMax®.

Display Mini Tracker Pane on Startup​

When TCMax® is started, the first column of the status trackers on the Dashboard panel will be displayed in a mini pane on the right-hand side of the Main Screen of TCMax®.

Play ‘Attention’ Audio for Status Trackers that have Exceeded their Threshold​

TCMax® will play the ‘Attention’ audio if any of the Dashboard’s default status trackers fall on or above the limits set in Settings > Dashboard Limits when viewing the dashboard panel.

Startup Page​

Selecting one of these radio buttons: Status Trackers, Custom Status Trackers, or Data Visualization, will cause the corresponding tab on the Dashboard to open by default when the Dashboard panel is opened.

Display Options​

Display User Preferred Assets when a User is Brought Up on the Main Screen​

The user preferred assets grid will display under the user’s issued items tab when the user is selected on the Main Screen. The user preferred assets grid will provide a list of assets that this user prefers, such as a favorite camera or weapon.

Enable Color Prompts for Issue and Turn-in Mode​

When an item is turned in, the screen will flash transparent yellow.

When an item is issued, the screen will flash transparent green.

When there is some sort of warning, the screen will flash transparent red.

This is helpful for high noise environments or for the hearing impaired.

Exclude Temporarily Transferred Items on Screens​

All items that are transferred using the Temporary Item Transfer functionality will not be displayed on TCMax® screens.

Filter the Issued Items View on Main Screen with the Same Filters in Issued Items​

The Issued Items List tab, on the Main Screen of TCMax®, will be filtered using the same settings the "Show Issued Items" screen uses.

Hide All Input Entered into Main Input Box​

All characters entered into the input box on the Main Screen will appear as hidden characters.

Hide Cost for All Items on Screen and in Reports​

Masks the cost field on the Main Screen and masks the cost columns in reports.

Load the Issued Items Screen Only Showing Filtered Items​

The “Show Issued Items” screen with display with the filter reversed, displaying only items that are filtered.

Load the Issued Items Screen with Filters Disabled​

The “Show Issued Items” screen with display with the filter disabled or turned off.

Only Show Temporarily Transferred Items in Screens​

Only the items that have been transferred via the Temporary Item Transfer function will be displayed in TCMax®. Once selected, you can also select the destination(s) that you would like any new items that may be added to reside.

Default the Issued Items Tab to Show on the Main Screen When TCMax® Starts​

When TCMax® is started, the Issued Items tab on the Main Screen will be the default view.

Default the Pictures Tab to Show on the Main Screen​

The Main Screen will automatically select the pictures tab to view when an item is displayed on the Main Screen.

Default the Log Notes Tab to Show on the Main Screen​

The Main Screen will automatically select the log notes tab to view when an item is displayed on the Main Screen.

Show “Item Quick Turn” Menu​

The Item Quick Turn @ Shift Change menu item will show on the top toolbar of the Main Screen when selected. If the option is not selected, this Item Quick Turn @ Shift Change will not appear on the top toolbar of the Main Screen.

Display Logo by Default Instead of EventLog Grid​

This will display the Logo you set in place of the Event Log Grid. When enabling, you will need to browse and choose a photo to set as the display on the Logo tab on the Main Screen instead of the Event Log tab.

Picture and Attachment Path​

The default source for pictures is C:\Users\Public\Documents\TCMax\Images but you can change that path by clicking the Set Path button. This is often required when on a server hosted Database as attachments will need to be stored on a shared network path.

Hardware and Third-Party Service Options​

Biometrics​

Enable Fingerprint Scanner​

Enable the use of our fingerprint scanner within TCMax®. When this option is enabled, you are presented with options as to how the fingerprint scanner will operate as well as a new tab to assign fingerprints to users within User Options.

Match Threshold​

The match threshold dictates how many points on your fingerprint need to match up with the fingerprint record in the Database. Secure is the most secure option as it matches up the most points. The Convenient option can speed up the fingerprint recognition process since it does not need to match up as many points.

Spoof Detection Level​

The spoof detection level protects against someone taking a picture or image of your fingerprint and using it to gain access to the system. Secure offers the most protection while convenient will read and process more quickly.

Usage Type​

The usage type dictates how the fingerprint scanner will operate within the system.

Verification mode will ask you for a fingerprint instead of a password on the various log-in screens.

Identification mode will use your fingerprint as both your user id and password on various log-in screens. This mode works in conjunction with the F2 shortcut on the Main Screen.

Use Fingerprint Authentication for Issue Turn-In​

This option will allow you to use the fingerprint scanner to display users on the Main Screen for the issue/turn-in process.

Barcode Scanners​

Serial Port Barcode Scanner is Connected On​

To use a serial port scanner, you must indicate the comm port that the scanner is connected to in this field.

Scales​

Display Weight in Metric Units​

This will display weights in metric units throughout various parts of TCMax®.

Signature Pad​

Automatically Clear Users Off the Screen After a Signature is Captured​

Once you sign for issued item(s), TCMax® clears the Main Screen.

Signature Pad Message​

Displays the desired message input on the signature pad when a user is prompted for a signature.

Snap-On ATC Configuration​

Show ATC Items Status in the TCMax® Dashboard​

TCMax® Dashboard will include ATC items in its queries.

Inventory Options​

Default Receive Inventory Mode to Update Quantities Based on Unit Quantity​

When using the receive inventory mode, the quantity updated will be based on the quantity in unit entered for that item by default.

Issue Options​

Ask for Expected Return Date when in Issue/Turn-in Mode​

TCMax® will add an expected return date to the issue process. This allows you to monitor items that are to be issued for more than one day and warn you via a report when items have not been returned by that expected return date.

Ask for a Control Number when in Issue/Turn-in Mode​

TCMax® will add an additional step and ask for control number when issuing items.

Allow the Issue of Chargeable Items that have not been Fully Charged​

Items that are not fully charged will still issue to users.

Restrict the Issue of Items that are Overdue an Inspection​

TCMax® will restrict issuing items that are overdue inspection unless you have permission to override inspection issue restrictions.

Limit the Number of Items a User can have Issued at One Time​

Entering the maximum number of items in the input box will prevent TCMax® from issuing more than that total number of items to any user.

Limit the Number of Items (of a particular Part Number) a User can have Issued at One Time​

Entering the maximum number of items in the input box will prevent TCMax® from issuing more than that amount of a specific part number to any user.

Force Users to Scan a Linked Chit after Each Item that is Issued​

When issuing an item, a chit barcode must be scanned after the item has been scanned to complete the process. Upon turn-in, the chit must also be scanned.

Facility Keys Require Password for Issue and Turn-in Functions​

This option will force a user to enter their password while issuing/turning in items that have the item type of Facility Key.

Do Not Allow Children to be Issued or Turned In​

Users will not be able to issue children individually from their parents.

Do Not Allow a Parent to be Issued if it has Missing/Overdue Children​

Items that have children will not be able to be issued if any of its children are issued or overdue on calibration.

Item Options​

Restrict Duplicating Barcodes that Exists Across the Database when Adding a New Item​

Barcode Ids must be unique per Shop Code. This option will not allow the same Barcode Id to be used in two different Shop Codes. It will make Barcode Ids unique across the entire Database instead of just per Shop Code.

Item Quantity Options​

Default Newly Created Items to a Quantity Zero​

New items added into TCMax® will have a zero quantity.

Default New Items to have the ‘Multiple Issue with a Single Scan’ Option Checked​

New items added into TCMax® will have the Multiple issue with a single scan checkbox checked.

Default New Items to have the ‘Multiple Items with This Same Barcode Number’ Option Checked​

New items added into TCMax® will have the Multiple items with the same barcode number checkbox checked.

Do Not Allow Issue when there are Not Enough in Stock​

TCMax® will not allow the issue of multiple quantity items if the input quantity exceeds the quantity available.

Default to the Issue Input Box on the Multiple Quantity Screen if Issuing is Available​

TCMax® will default the cursor placement to the issue quantity field regardless of if a user already has a quantity issued of the scanned item.

Login and User Options​

Allow Users to Set Item Status Without Being Logged In​

If a user is scanned on the Main Screen of TCMax®, items will be able to have their status changed.

Clear Main Screen When Same User Id is Entered Twice​

Scanning the barcode of the current user displayed on the Main Screen of TCMax® will clear the Main Screen.

Close TCMax® When the Windows User Account is Locked​

This option will close TCMax® when the Windows account the user is logged in with is locked. This can help customers using LocalDB when users forget to close the software before locking their accounts which causes Windows to lock the LocalDB service to their account.

Display User Organization and Shift​

TCMax® will display organization and shift information for users on various screens throughout the software. To create shifts, you must set them up using the Shift Setup screen. The shift indicator on the Main Screen of TCMax® must be changed manually to indicate the current shift. If you attempt to issue items to a user that is assigned to a different shift, TCMax® will first say “Attention”, and then it says “Issue” as necessary.

Display Login Prompt at Startup​

TCMax® asks for a login when launched.

Do Not Allow Access to Log Search Screen Without Logging In​

This prevents the ability to open the Log Search screen without a user logged in to TCMax®.

Hide User Id Field on Main Screen​

All user ids will be removed from various screens in TCMax®.

Link Windows IDs to TCMax® User Accounts​

TCMax® will look at the computer’s Windows Login ID to see who has already logged into the computer. If it matches a record in the database, then it will automatically log the person into TCMax®.

Require Someone to be Logged in Before You Can Perform an Issue or Turn-In​

Before items can be issued or turned in, a user must be logged into TCMax®.

Restrict Reports to Those With Permission Only​

Before anyone can view any reports, they must be given permission through the Settings > User Options screen and then logged in to TCMax®.

Automatically Log User Off After Selected Number of Minutes​

TCMax® will log users off after the desired number of minutes have passed without any activity.

Automatically Clear User on Main Screen After Selected Number of Minutes​

TCMax® will clear the Main Screen after the desired number of minutes have passed without any activity.

Password Options​

When entering a number greater than zero (0) into the entry boxes the options will then be enabled in the TCMax® software.

The first option, Password must be a minimum of ___ characters, requires a minimum length to be set when assigning a user a password.

The second option, Users must change their password every ___ day(s), requires users with a password to change their password every 'x' amount of days.

info

A Password Policy feature was added in TCMax® Version 9.8.9160.18261.

If you are using both the Password Options from Settings and the Password Policy feature from User Options, passwords must satisfy both options (both validations will be applied).

Printer Options​

Print 2 Copies of a Receipt​

Prints 2 copies of the receipt from the specified receipt printer for each transaction.

Print Receipt at End of the Issue and Turn-In Actions​

TCMax® automatically prints receipts when a user is displayed, and the Main Screen is cleared afterwards. When selecting this option, you will also have a choice to Always print receipt (Even if it is blank).

Include Barcodes on the Receipts​

Prints the barcode of issued items on the receipt. When selecting this option, you will also have a choice to Include turn-in barcode on receipts that will be located at the top of the printed receipt.

Include a Barcode to Return All Items at Once on that Barcode​

Prints a “Return All” barcode on the receipt that will return all issued items on the receipt with a single scan.

Include a Message on All Receipts​

The message entered in the text box will appear on all receipts printed.

Hide Long Term Items on Receipt​

All items that are issued to a location of long term or are marked long term within the 'Show Issued Items' screen will not be visible on the printed receipt.

Ask for Quantity of Labels When Printing Item Labels​

TCMax® will ask you how many labels you would like to print when using print label buttons throughout TCMax®.

Report Options​

Automatically Print an AF 1297 at the End of the Issue/Turn-In Process​

An AF 1297 is automatically printed to the page printer when either the TCMax® Main Screen is cleared or you switch usernames.

Automatically Print an Issued Items Report at the End of the Issue/Turn-In Process​

An Issued Items Report is automatically printed to the page printer when the user is cleared from the Main Screen, or you switch usernames.

Automatically Print a DA 2062 Report at the End of the Issue/Turn-In Process​

A DA 2062 report is automatically printed to the page printer when a user is cleared from the Main Screen, or you switch usernames.

Transfer Options​

Auto Transfer Items to the Currently Selected Shop Code​

When an item is scanned that exists in a different shop, it will be transferred to the shop that is currently selected in the drop-down menu from the upper right-hand corner of the Main Screen.

Turn-In Options​

Ask for Current Miles/Hours When an Item is Turned in with Miles/Hours Greater Than Zero​

When you turn in an item with miles or hours greater than zero, TCMax® will ask you to enter the current miles or hours and update the respective values accordingly.

Use Issued Location for Turn-In​

When turning in an item, the location that the item was issued to will be written to the location field for the turn-in log record.

Use the Currently Displayed User on the Main Screen for Turn-In Records​

The person displayed on the Main Screen at time of turn in will have their name associated with the turn in records.

The User Logged in Cannot Turn-In Their Own Items​

The person who is logged into TCMax® will not be able to turn in items that are issued to their user ID.

Prompt Before Turning in Another User’s Items​

When a user on the Main Screen scans an item that is issued to a different person, TCMax® will ask if the intent is to turn that item in.

Only the User Who Took an Item Can Turn it Back in​

The user who is issued an item must be displayed on the Main Screen to turn that item in.

If an Item is Turned in Within One Minute of Being Issued, Delete the Log Records for that Transaction​

When an item is turned in within one minute of being issued, the issue / turn-in log records for that item is removed from the logs.

Facility Keys Require 2nd User for Turn-In​

This option will force a person other than the one to whom the Facility Keys were issued to turn the facility key(s) in.

Do Not Display User Selection When Turning in a Multiple Quantity Item That Does Not Allow the Issue of More Than One at a Time​

When scanning an item that is multiple quantity and doesn’t allow more than one issue at a time, if there is a user on the screen, the item will either be issued or turned in. If no users are on the screen, a selection list will appear.

Do Not Allow Turn-In Actions to be Performed Unless Someone is Logged In​

Checking this option requires someone to be logged into TCMax® to be able to turn in items.

Do Not Allow a Parent to be Turned In if it is Missing Children​

This prevents someone from turning in a toolbox/kit (parent) that has items that are missing.

Check to Require a Username and Location Before a Turn-In can be Performed​

Checking this box forces you to enter a user id and location for an item to be turned in.

Check if a Second User is Required to Turn-In Items​

If a person tries to turn in their own items an “Attention” audio is heard and a message of “Second User is Required for Turn-In” will populate, and the item will not be turned in. To turn in the item, a different user must enter their Id on the Main Screen.

Ask For the Number of Times an Item was Actually Used When the Times Used is Greater Than Zero​

When an item is turned in that has a Times Used value greater than zero, a prompt will say “Attention” then ask you to enter the number of times this item was used during this issue period. That number is added to the Times Used.

Ask for Items Marked as Chargeable, if the Item Needs to be Charged​

When an item marked with "Requires Charging" is turned in, TCMax® will ask if the item requires the charging. Selecting Yes will not allow the issue of the item until the charging duration is complete. Selecting No will ignore the charging duration and allow the issue of the item at any time.

Work Location Options​

Display Location Buttons​

When TCMax® asks for a location, it will display a new window with locations as buttons to choose from. The locations displayed in this window will be compiled from the displayed grid in Options under Location Buttons and from the Set Locations Status screen.

Location Buttons​

You can add new locations that will be displayed as buttons in this area (if that option is checked). Enter the location in the New Location box then select from the Shop Code dropdown, what shop code this location corresponds to (if it applies to all shops select the “All” option from the dropdown), then click the Add Location button. Clicking the Allow only buttons for use in setting a Location checkbox will force a user to select one of the provided options instead of also having an input box where they can type a location that is not given.

Do Not Allow Location to be Blank​

A location will be required in the Location field before being able to scan items when issuing.

Do Not Ask for a Location When Issuing Items​

TCMax® no longer asks for a location or displays that field on the Main Screen.

Show Button and Enable Setting of Default Location for Individual Users​

Enables the ability to set a default location for individual users. When set, the user enters their User Id, the Default Location automatically appears, and they are ready to issue items to that location.

To set a Default Location, enter a User Id and enter a Location as normal. The Set Default button appears to the right of the Location text box. Select the button, the default is set, and the button changes to Un-Set Default. To un-set the Default Location for this user, just click the Un-Set Default button.

Check to Make Sure Location are not Existing User or Item Barcodes​

When entering a location in TCMax®, an “attention” will play if you enter in a user or item barcode, preventing you from using that location.
