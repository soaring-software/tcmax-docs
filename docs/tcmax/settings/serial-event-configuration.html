Serial Event Configuration

Available in TCMax® Version 9.8.9116.26749 or newer.

The Serial Event Configuration is used to configure the setup of serial devices. The main purpose of this feature is for anyone who wishes to configure issue, turn-in, and user events from the Main Screen and bridge it with a hardware device. A user must have the "Access TCMax, Lock, and Dashboard Options" permission enabled to utilize this feature.

Utilizing Serial Event Configuration​

The setup for Serial Event Configuration can be found from the Main Screen of TCMax® by going to Settings > Serial Event Configuration.

Creating Serial Event Configurations​

To create a Serial Event Configuration, select Click to Edit Event Configurations.

This will produce a Serial Event Manager Confirmation screen. Select Add Config.

Give the Event Configuration a name in the Event Config Name field; Names must be unique.

Once a Configuration is added, you then have the ability to use the default for events or you can adjust the information that will display.

info

The only information that can be selected for each specific Event is what is listed in the Available Objects under each Event.

If information is adjusted and you need to resort back to defaults, there is a Reset to defaults button to go back to the original configuration.

Available Events​

The following Events are available once a Configuration is created:

  • User Logged In
  • User Logged Out
  • User Scanned
  • User Cleared
  • Item Issued
  • Item Turned In

Selecting a Serial Event Configuration​

To select an Event Configuration, refer to the Selected Event Configuration section and select the drop down menu to view all Configurations.

Choose the Configuration you would like to use. Once the Configuration is selected, you are able to adjust your Com Port, Baud Rate, and Flow Control. Flow Control is a serial communication feature used to manage and configure how data is transmitted through serial ports.

By default, we populate any Com Ports we find a connection to or you are able to manually enter a Com Port if you know which one you will be using.

When the Com Port, Baud Rate, and Flow Control have been configured, press Done to Save those changes.

Deleting a Serial Event Configuration​

To delete a serial event configuration, select Click to Edit Event Configuration.

This will produce a Serial Event Manager Confirmation screen. Select the Configuration you would like to delete by choosing it on the left-hand side of the screen. This will highlight the Configuration blue.

With the Configuration highlighted, press Delete on your keyboard. When that is completed, select Save for changes to take effect.
