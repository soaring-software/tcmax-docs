How to Use TCMax to Track Evidence for Law Enforcement

Preparation for evidence tracking​

When you are installing TCMax for the first time you will be asked what type of database you wish to use. You will want to select Blank Database. Once TCMax has been installed the very first time you run TCMax you will be taken to the Preferences screen to set up your printers. The first things we will do to enable Evidence Tracking will be done from this Preferences screen. If you’ve already run TCMax and are looking to enable Evidence Tracking you can log into TCMax either with the login you’ve created or with the default 01 employee number and 01 for the password. The first place we should go is Maintenance> Preferences.

You will want to locate the arrows on the top right of the window. Hit the right arrow a few times until you see the Captions 2 tab. From the Captions 2 tab Click on the {POLICE} button to reassign the captions on the main screen to be more appropriate to the tasks you will be performing. Once you’ve done that click OK and you will be taken back to TCMax’s main screen.

Deciding how to identify people​

TCMax differentiates between people and things by character count. When you first logged in you used an employee number of 01. That is two characters, the 0 and the 1. In the Preferences area TCMax is set up by default to know that if you input 2 characters you are dealing with an employee. There are four character counts total that you can associate with employees. By default those values are 5, 2, 16, and 18. This means that if you type in a value or scan a barcode with 5 characters TCMax knows it’s an employee. If it has 16 characters, TCMax knows it’s an employee. 18 characters…employee. Any other character count will be considered an item instead of a person. These values can be changed by you at any time but you really want to decide how you’re going to identify yourselves from the start and stick with it. Otherwise you’re going back and reworking your data which is not necessary if you plan properly.

It is recommended that you find some sort of identifier that all personnel have (for example, a badge number). You simply want to find a universal character count that can be used to identify your people. If your badges typically have 2 characters in them, for example, 73 but you have an employee with the badge number of 6, simply enter them into the system as 06, this way it is still 2 characters.

To alter the amount of characters TCMax associates with employees simply go to Maintenance>Preferences and click on the ID Cards and Item Barcodes tab. At the bottom of that page you will see Employee ID Card#1 – 4 as seen below.

In the above setting we’re telling TCMax that 2, 5, 16 and 18 are going to be employees, every other character counts will be considered items. As an example, if you want to use a 4 character value to identify your employees (last 4 of SSN or phone number, etc) simply change the value in one of these boxes to 4. If you’re certain that you want to use 4 and only 4 characters to identify your people you can put 4 in all of these boxes or 4 in one and 0 (zero) in the rest as seen below. This way all other character counts are open to be considered items.

While you’re on this preferences tab go to the top of the screen and find the Employees Prefix and Suffix area. This area allows you to tell TCMax how you want to auto-number people. Your law enforcement personnel will have a badge number which you can use to identify them but when property owners come to claim their personal items you will want TCMax to assign them a number. It’s not important what the number is; only that it is unique so you’ll be able to reference the transaction of returning their property to them at a later date.

In the example above, we’re telling TCMax we want 4 characters to be considered an employee. It is important that whatever we put in the Employee Prefix and Suffix adds up to a total of 4 characters. Put an “A” in the Employee Prefix and in the Employee Suffix type “000”. When you tell TCMax to automatically generate a number it will generate the number “A000”. The next time you tell TCMax to generate an employee number it will generate “A001” then “A002” etc.

The prefix you set can be alpha/numeric but the suffix must be numeric because TCMax will automatically increment by 1 each time you create a new item. This way every new employee gets a unique number. The nice thing about using this A000 numbering system for your property owners is upon first glace you’ll be able to tell that this person was a civilian because of the preceding “A”. If their number was “2423” you can assume that is some sort of law enforcement badge number.

Again, you are not forced to use a 4 character identifier for your employees/personnel as I’ve shown in this walkthrough. The important thing is that you use a character count that is constant so your people don’t conflict with your items. Once this is set up, you shouldn’t have to change it. The instructions on the next pages will give you a step by step guide to adding new people once this preferences area has been set up.

Setting Up Common Work Locations​

TCMax uses Work Locations during the issue process to help you track where your evidence is going when it leaves your evidence room. If you would like to add additional common work locations (forensics lab, court, etc) from the main screen of TCMax go to Maintenance>Preferences and click on the Gen Req 5 tab. Make sure the “Display Work Locations in buttons” option is checked and simply add your common work locations to the grid in the bottom left as seen below:

Adding Law Enforcement Personnel to TCMax​

  1. From the main screen of TCMax, in the colored box in the top left, type in the person’s badge number and hit enter. In this example we will use the 4 character badge number of “1234”.

  2. If this employee has not been entered in to TCMax yet, TCMax will say “new employee” and the cursor will drop to the Employee Name box. Simply type in this person’s name and click the Save button. You can also assign them an organization and shift should you desire.

  3. If you wish to issue something to this person you will have to retype their number into the main input box in the top left and follow the “To issue items” instructions located on the main screen.

Adding Property Owners to TCMax​

  1. From the main screen of TCMax hit the F4 key. TCMax will automatically generate a number for this new person and you will hear “new employee”

  2. The cursor will drop to the Employee Name box. Simply type in this person’s name and click the Save button. You can also assign them an organization and shift should you desire.

  3. This person has now been added to TCMax. If you wish to issue something to them simply retype their number, in this case “A000”, into the main input box and follow the “to issue items” steps located on the main screen.

Adding Suspects into TCMax​

Technically TCMax treats suspects the same way it treats the evidence. Suspects should not be entered in as employees. The only employees you should have are people that are signing out or turning in evidence. Tracking suspects the same way you track evidence allows you to easily pull up a case and see all evidence and suspects involved in the case. To add suspects use the following steps:

  1. Hold down the control key on your keyboard and hit the F3 key. TCMax will say “New Item” and automatically generate a unique ID number for this suspect. You may notice that the identifier TCMax generates begins with “SUS”. The main goal of this is to allow you to easily identify this item as a suspect just by looking at that number. After hitting the Ctrl + F3 your screen should look as follows:

  2. Next you will enter in the suspect’s name in the Item Name field and possibly the suspect’s SSN or contact number if you have it. Enter the “Case Number” of the crime this person is suspected of. You will also notice the “Is Suspect” box in the Custom tab is checked for you. This will allow you to run a report that lists only suspects. When you’re done entering information, your screen should look similar to the following:

  3. Once you’re sure your data is correct simply click the “F5 to Save” button on the screen or hit the F5 key on your keyboard.

  4. Congratulations, you’ve just added a suspect and associated them with a specific case.

Adding Evidence to TCMax​

To add evidence to TCMax you must first be logged in as someone who has permission to add new items and use the following steps:

  1. Hit the F3 key or go to Maintenance>New Item. TCMax will automatically generate a unique ID number for this item. The right side of the screen, where TCMax stores data on each item, will also be opened up for editing as seen in the screen shot below

  2. Type in any relevant data you have for this item such as Case Number, Item Name, Storage Location, Property of, where and when it was collected and who it was collected by. Only put info in the fields you have data for. None of these fields are mandatory but the more you enter, the more use you’ll get out of the information down the road.

  3. After you’ve entered all relevant data simply hit the F5 key on your keyboard or click the blue “F5 to Save” button in the top right of the screen.

  4. Congratulations, you have just added a piece of evidence. If you would like to print a barcode label for this item simply click the “Print Item Label” button located in the middle-right of the main screen.

  5. To add another piece simply repeat steps 1-3.

Preparing to Return/Destroy Evidence​

Once you’ve received orders to return or destroy evidence you can tell TCMax that you will be destroying or returning these items at a later time.

  1. From the main screen of TCMax click on the Item Search menu option.

  2. Once on the Item Search screen, TCMax should be showing you all the items in your database. Rather than scroll through the entire grid looking for a few specific items, we suggest typing in the Case Number of the items to be destroyed in the Case Number field towards the top of the screen. Once you’ve typed in the Case Number hit the “Enter” key on your keyboard.

  3. Now only items/suspects belonging to this case are displayed in the grid at the bottom of the screen. You could filter this grid further by entering in part of the item’s name. If you type the word “powder” into the Item name box, and leave the case number you already entered in that box then TCMax will only show you items that belong to that particular case with the word “powder” in the name field.

  4. Once you locate the item(s) you wish to destroy or return simply select them from the grid and click the appropriate button. Either Prepare to Destroy or Prepare to Return. In this example I will be destroying item number 00013. Once I click on the Prepare to Destroy button TCMax asks for confirmation that I indeed intend to mark this for destruction at a later time.

  5. If you click “Yes” you will be prompted with another message box asking you to enter any notes you see fit to enter. For example, if you wish to record by whose authority you’re destroying /returning items, you could type in “so ordered by Judge Williams” or something similar. If you do not care to enter notes simply leave that box blank and click “OK”.

  6. The same steps apply to marking items as returned. All you’re doing at this point is changing the “shop code” these items belong to and possibly adding a note to explain why you’re doing this. The main function of this step is to allow you to differentiate between your current evidence with trials/investigations that are on-going from the items just waiting to be picked up by their owners or destroyed by authorized personnel.

Destroying or Returning Evidence in TCMax​

  1. From the main screen in TCMax, in the colored box in the top left of the screen, type in the ID number of the person that will be receiving or destroying the items and then hit “enter” on your keyboard. TCMax should respond by saying “Employee”.

  2. You will then be shown a screen with your common work locations as buttons. Click the Destroyed, or Returned button as applicable.

  3. Once you’ve hit the correct button you will be taken back to TCMax’s main screen. Simply type or scan the number of the item(s) you are destroying or returning.

  4. Each time you type or scan an item you should hear TCMax say “Issue”. Once you have finished issuing everything to this person hit the F6 key on your keyboard to begin the signature capture process.

  5. A window will appear with the transaction details on it. On your LCD Signature Pad you will also see the transactional data. The first signature will be the person that is doing the issuing. This is your Evidence Room Attendant and will be the person who is logged in and operating TCMax.

  6. Once that person has signed and clicked ok on the signature pad you will be prompted to have the person receiving/destroying the items sign. Their name will also appear on the signature pad. Once they’ve signed they can click “ok” on the signature pad and the transaction ends.

  7. You will notice that a spreadsheet opens and the transaction data is placed into the spreadsheet along with the two signatures. The spreadsheet will automatically close itself and saves to whatever folder you told it to save to during setup.

Searching For Items​

There will be times when people come in to have their property returned to them or a detective is looking for a specific item. At these times you may not always know exactly where every item in your inventory is. TCMax has made finding these items very simple. Just use the following steps:

  1. From the main TCMax screen, go to the Item Search menu option.

  2. The bottom half of the Item Search screen contains a grid with all of your suspects and evidence listed in it. The top half contains filters for you to narrow down the results visible in the grid at the bottom. If you have 5,000 pieces of evidence you won’t want to be digging through the grid to find the one you’re looking for. Simply use the filters up top to narrow down your search field.

In the screen below we see an example Item Search screen.

You can see that you can search by ID Number, Case Number, Name, Location, etc. If someone were to come in asking for an item that belonged to case 08-0003N you could type that into the Case Number box up top and only items associated with that case number would be displayed at the bottom as seen below:

In this example we only show 2 results associated with that case. It is now much easier to find the evidence we were looking for as we only have 2 choices and can see the storage location of both items is Shelf 1.

You can resize any of the columns in the grid at the bottom as well as sort the grid by each column. If you would like to sort this grid alphabetically by name simply click on the column header (the actual words “Item Name”) and TCMax will sort the grid A-Z by based on the item’s name. If you click the same header again TCMax will reverse the sort to Z-A based on the item’s name.

Another useful item on the Item Search screen is the “Show Pending Items Only” checkbox. Checking this box will only display records in the grid that are not currently issued out.

Searching for Suspects​

In another example, we’ll search for suspects. From the Item Search screen simply type SUS in the ID Number box up top.
