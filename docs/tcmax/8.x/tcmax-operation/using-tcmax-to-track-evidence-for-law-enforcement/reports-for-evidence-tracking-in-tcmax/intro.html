Reports for Evidence Tracking in TCMax

General Report Info​

There are a few things to be aware of concerning all reports. The majority of TCMax reports can be found by going to Other Reports from the main screen. On that Other Reports screen you should notice some time and date filters in the top right corner as seen below:

When running reports that are dealing with historical data you can change the time/date range that TCMax is populating the reports from. You may want to run a “history of issue/turn in by Employee” report which will show you every item a particular individual has been issued. If you ran that report with the time/date filters shown above the report would list every issue/turn in that employee has had within the last calendar year. If you were only concerned with the issue/turn-ins this employee had during the last week, you could change the date range box’s value from “Year” to “Week”. You could also put in exact times or dates to refine your searches by.

Another thing to keep in mind concerning the Other Reports screen is your ability to export the report data into a PDF or Excel Spreadsheet. Towards the bottom of the Other Reports window you will see a check box for “Create Report.pdf & .xls when report closes”. If you check this box and run a report TCMax will create 2 files named Report.pdf and Report.xls. The location where TCMax stores these files is set up by you the first time you try to save a PDF or Spreadsheet. If you forget where you set these files to save you can click on the About menu option from TCMax’s main screen. At the bottom of the About window you will see “Path to report pdf files”. This is the location TCMax is saving these files to. It is important to note that each time you do this TCMax will create a Report.pdf and Report.xls so if a previous Report.pdf exists it will be replaced by the new one. If you want to keep one of the Report.pdf or Report.xls files you will want to navigate to that folder and rename it before you try to export another report.

Reports Specific to Evidence Tracking​

There are two reports that have specifically been added to help with Evidence Tracking. The first can be found by going to Other Reports from the main screen in TCMax. On the Other Reports screen, click the Special tab and the last report on that tab is the Shop Code Transfer Report. Running this report will show you a history of items that you have marked as needing to be destroyed or needing to be returned to owner as seen below:

In the above report we can see the date items were marked as needing to be returned/destroyed, who did the transfer, the reason for the transfer as well as other useful information.

The other report specific to Evidence Tracking is located in Other Reports and is at the bottom of the Customer tab. The report is named Police Property Receipt. This is basically a chain of custody report. When you click on this report an Enter Data Here box appears at the bottom of your screen. Enter in the ID Number for a specific item or enter a case number for all evidence associated with that case. Either way TCMax will return 2 reports. The first will be a listing of all items in question. If you run this report for one specific piece of evidence only that piece will show up on the first report.
