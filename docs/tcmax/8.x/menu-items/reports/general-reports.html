General Reports

Issued Items Report​

This report displays all the items issued to each employee, where the items are located and when are they expected to return.

Number of items issued to individual employees​

This report displays a list of all (or a selected) employees and the number of tools they currently have issued.

Items currently issued grouped by Employee Number​

This report displays all the items that are currently issued and groups them on the report by the employee number that they are issued to. The data box allows you to enter a work location in the box to limit the report items to the specified work location

Items currently issued to a particular employee grouped by Location​

Use this report to print packing lists when you deploy. When packing your items, create a fake employee with the name of the deployment. Each time you load a piece of equipment or item box on the pallet, scan the deployment employee, and then enter the pallet number or increment number for its location. Then scan the equipment. When you finish packing, run this report entering the employee number that was used to issue all of the equipment and items. The report develops a separate page for each pallet. It also calculates the total weight of a cube for each pallet.

Items currently issued to a particular Organization grouped by Employee Number​

This report populates Organization Names in the dropdown box to the right, allowing the user to run a report that shows all the tools that are issued to employees of a specific organization, then groups those tools by the employee they are issued to.

Items issued to a particular location grouped by Employee Number​

Use this report when you have issued a number of items to one location. It reports all items, sorted by the employee that they were issued to. Military units packing for a deployment can use this report as a packing list complete with total weight and cube.

Items currently issued to a particular Location grouped by Employee Number (simplified)​

This report requests search criteria in the data box, of the work location that items were issued to. This report will then display the tools that are issued to that work location and are grouped together by the employee they are issued to. This report only contains basic information of the tools issued.

Item Inventory​

This report is a general purpose item inventory report.

Item inventory items currently issued​

This report is a general purpose item inventory report that only displays items that are currently issued.

Item inventory items remaining on the shelf, not issued​

A general purpose item inventory report that displays items not currently issued.

Item Inventory Expendable items only​

This report is a general purpose item inventory report that only displays expendable items.

Item Inventory Tool room, No Children​

Inventory of all items that have no children, and are not children of any kit.

Item Inventory of Parents Only​

An inventory report that does not include any children.

Item Inventory Grouped by Vendor​

An inventory report that groups all items in the report by the data entered in the vendor field for the tool.

Item Inventory with Separate Page per Parent Barcode​

A general purpose item inventory report in which items are grouped by parent barcode number. This report can be used to create a complete item list for each individual itembox such as the U.S. Air Force’s (TAL).

Item Inventory with Separate Page per Storage Location​

This report groups items by location, printing a complete inventory of all items in the database.

History of issue/turn-in by Location​

Find part of an item in a location? Run this report, giving the location and it tells you every item ever taken to the location, and who took it. Trace down that broken item given the location the part was found in.

History of issue/turn-in by item​

This report allows a user to display and/or print the entire history of any item from the item issue LOG. Pressing Item History brings up a small screen that asks you to enter a barcode number. Enter the barcode number then press the Run Report key. The report displays date and time that any user issued the item or turned it in along with the location that was entered. No password is required.

History of issue/turn-in by Employee​

This report allows a user to display and/or print the entire history of an employee.

History of issue Non-Expendable items​

This report gives a complete history of the issue of all non- expendable items. Everything that does not have the ‘no turn in’ box checked will display in this report.

History of issue Expendable Items​

This report gives a complete history of the issue of all expendable items. (Items that have the ‘no turn in’ box check)

History of issue Expendable Items by Employee Name​

This report gives a complete history of the issue of all expendable items that are grouped by employee name. Use this report to find out if any employee is using excessive amounts of expendable items.

History of issue Expendable Item Issues grouped by Employee​

This report gives a complete history of the issue of all expendable items that are grouped by employee name. Use this report to find out if any employee is using excessive amounts of expendable items. This report allows the report to be ran using work location as search criteria

History of issue Expendable Items Grouped by Shop then Name​

This report gives a complete history of the issue of all expendable items that are grouped by Shop code first, then ordered by the name of the item.

Reorder Report​

Items that have the Do Not Reorder check box checked and that have minimum quantity in stock and maximum quantity in stock entered will appear on this report when you are required to reorder the item.

Enter purchase order number, date ordered and quantity ordered. Once on order, the quantity on order will reflect in the Reorder report. Check the Do Not Reorder box and this item will be removed from the Reorder report.

Inventory Received​

A History of inventory that has been received through the receive inventory mode.

Purchase Orders not Received​

Open purchase orders appear in this report.
