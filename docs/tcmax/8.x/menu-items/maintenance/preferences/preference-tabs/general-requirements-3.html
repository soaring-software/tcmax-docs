General Requirements 3

Options for Issuing Items (Continued from General Requirements 2: Tab 2)​

Number of days from today for default ‘Expected Return Date’​

The expected return date (if turned on) defaults to today. Some customers want that defaulted to some other time in the future. Enter the number of days from today.

Do not allow items to be issued to an employee with overdue returns​

If the employee has items that are overdue turn in (return date option must be turned on) then TCMax says “Attention” and will not allow you to issues until they return their overdue items.

Multiple Quantity Item Options​

Do not allow issue when there are not enough in stock​

When not checked TCMax assumes that if you issue a quantity of items that you must have the items in hand and know that they are there. If the inventory count in TCMax says you don’t have enough it still issues them. When you check this box, and TCMax thinks that you don’t have enough, then TCMax says “Attention” and tells you that there are not enough available.

Default new items to have multiple items with the same barcode number​

If the majority of your items are allowed to have multiple items with the same barcode number and therefore allowed to be issued to multiple employees under a single item barcode number then you should check this box. When new items are created the Multiple items with this same barcode number box will automatically be checked.

Default new items to allow multiple issue with single scan​

If the majority of your items are issued in quantities of more than one at a time then check this box. When new items are created the Issue multiple of this item with single scan check box will automatically be checked for you.

Always display selection list for multiple items with the same barcode number​

If checked, this option will force the employee selection list to appear to select who the items that are being scanned are turned in from.

Consume option when multiple turn-in is short​

This option when checked is used in a manufacturing environment where you may take a quantity of items on the job with the intention of leaving some or all on the job. For example, in an aircraft manufacturing plant you take 50 bolts on the aircraft. 45 of them are used in the aircraft to bolt things together, and will stay there for the life of the aircraft. When you leave the aircraft you take the five extra ones out and turn them in. When you scan the barcode number for the bolts you enter -5 (minus five) to turn those five in. With this box checked TCMax will say “Attention” and a prompt will ask you if the “other 45 have been consumed on the job.” If you click Yes then the other 45 are removed from the issued items list, and a separate Log entry is made showing their consumption. These ‘consumed’ items will appear on the special “Customer” Consumable Use Log report.

Turn In Options​

Do not allow turn in unless someone is logged in​

As it says, you do not need to be logged in to issue items, but you must be logged in to turn things in.

Person logged in cannot turn in their own items​

With this option checked, the person who is logged into TCMax will not be able to turn in items that are issued to their employee number.

Only the person who took an item can turn it back in​

Other people cannot turn in your items, only you can turn in your items.

Check if a second person is required to check in items​

This option when not checked allows a person to check in his or her own items. When checked, if a person tries to check in their own items a warning audio is heard “Second Person Required for Turn-In” and the item is not turned in.

Check to require an employee name and location before a turn in can be performed​

Checking this box prevents items from being turned in when you want them displayed on the screen, but have no employee/location combination on the screen. Without the box being checked you can turn things in without an employee name.

Prompt before turning someone else’s items in​

TCMax asks you to be sure that you wanted to turn in someone else’s items.

Do not allow a parent to be issued if it has missing/overdue children​

As it says, prevent someone from issuing a tool box that has overdue items or items that were previously issued.

If an item is turned in within one minute of it being issued, delete its original log record​

By default this box is checked. If you should accidentally issue the wrong item, scanning it again right away turning it back in causes the LOG record for that issue to be deleted. This keeps your usage records to be more accurate.

Ask for current miles/hours when an item is turned in with miles/hours greater than zero​

As the title suggests, when you turn in the keys for a vehicle, TCMax will ask you to enter the current miles or hours to keep that updated easily.

Update using default storage location when turning in items​

All items that are turned in on a computer with this item checked will have their storage location changed to whatever is typed in the Default storage location box.

In this instance the storage location for all items turned in using this computer will have their storage location changed to Toolbox 100.

Inventory Mode Options​

Start PC in Physical Inventory mode​

When this box is checked and you start TCMax it will automatically be in the physical inventory mode. The default without the box checked is the Issue / Turn in mode*.*

When in Physical Inventory Mode, adjust ‘Quantity on Hand’ when multiple item quantity is short​

This is not a suggested option for normal use. When performing a Physical Inventory, if you enter a quantity for a multiple quantity item that is less than what TCMax shows, the Qty on Hand for that item will be changed to reflect the lesser quantity. For example, if the item shows as having a quantity of 20, but when the physical inventory is done there are only 15, the quantity for that item in TCMax will be changed to reflect 15.

Update Inventory Date when in Physical Inventory mode and an item is turned in​

The Inventory Date field in the Stock table is also updated when any barcode is scanned while in the Physical Inventory mode. This makes better use of the inventory reports.

Physical Inventory Mode uses Max in Stock value for ‘Issue Multiple’ items instead of Qty on Hand​

There are times that you want to issue expendable items but when doing a physical inventory be prompted to replenish those expendable items back up to the max in stock value. This turns that ability on.

Automatically turn in children when a parent (that has a parent) is scanned in Physical Inventory mode​

Used for special inventories and restocking inventories of things like containers of items and equipment.

Display End of Shift Mode menu option​

The End of Shift mode is designed to help you inventory items that are currently issued at shift change. Checking this box will add the End of Shift menu option to the menu on the main TCMax screen*.*
