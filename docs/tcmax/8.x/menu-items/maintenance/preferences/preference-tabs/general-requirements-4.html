General Requirements 4

Display Options​

Enable color prompts for issue and turn-in on the main screen​

For high noise environments or for the hearing impaired, check this box and when an item is turned in the screen for a few seconds will turn transparent green, and when an item is issued it will turn transparent yellow, and finally when there is some sort of warning the screen will turn transparent red.

Show ‘Item Quick Turn @ Shift Change’ menu option​

The Quick Turn @ Shift Change menu item is used when you have a multi-shift operation and want to allow items to be transferred without actually scanning each individual item. It allows you to pick all items issued to an individual or to a location and transfer them to the employee already on the main screen.

Start items out screen in Reverse Filter mode​

This checkbox will start the “Show Items that are out screen” in reverse filter mode when entering that screen.

Start items out screen in Filter Stopped Mode​

This checkbox will start the “Show Items that are out screen” with the filter turned off

Display Log Notes only in the CTRL-S grid​

Converts the CTRL-S grid on the main screen to show the historical log notes for the item displayed on the main screen ordered by date/time descending.

Filter issued tools on the main screen viewed via CRTL-S​

When using the CTRL-S option on the main screen, the items will be filtered according to your settings in the “Show Items that are out screen”

Log display is filtered by filters in Show Items that are Out screen​

Check this option and the filters that are applied in the Show Items that are Out screen apply to the employee log table. When an employee number is entered, a log appears in the bottom left of the screen showing you what items the employee has issued to themselves. Long term items can be automatically hidden by checking the box above, and issuing the item to a special location such as “Long Term” or “Permanent” or whatever, and adding that same text to a filter in the Show items that are out screen.

Default the Pictures tab to show on the main screen​

Check this box and when you start TCMax the Pictures tab will be placed in front. You can select other tabs as normal, this simply causes the pictures to come up when you start the program.

Display Duplicate button on main screen, used to duplicate items for multiple shop codes​

When checked and you bring up an item on the screen you will see a Duplicate Across Shops button. You can add that exact item (with a different barcode number) to another shop code with a single click.

Also displayed is another button Duplicate X Times button. Bring up an item on the main screen, click the button and TCMax will ask you how many duplicates you want. Enter something other than zero and TCMax will use the next available barcode number and add the appropriate duplicates to the database with new barcode numbers. TCMax will also ask you if you want labels printed.

Display ‘Employee Preferred Equipment’ in LOG table with an employee ID scan​

With this option checked you can setup Employee Preferred equipment. This will display a list of things that this employee prefers to have, such as a favorite camera or weapon.

Hide Cost for all items on screen and in reports​

This menu option changes the cost on the main screen to asterisks and makes cost columns in reports invisible.

Default new item quantity to zero​

With this option checked, all new items entered will have a ‘0’ (zero) entered for their quantity.

Default new item min/max by part number to checked​

This option will cause the Min/Max by Part Number box to be checked for all new items entered into TCMax.

Hide all input entered into main screen search box​

This option will make all information entered into the main input box on the main screen appear as asterisks (*).

Display Log Notes only in the CTRL-S grid​

Having this option checked and with an item displayed on the main screen, when you hit CTRL-S a grid will appear and show you a history of log notes for that item.

Miscellaneous Options​

Ask for the number of times this item was actually used​

Examples will be crimping items, go/no go gauges, you may have to do an inspection based on the number of times the item is used. Check this box, the captions for Current Miles change to Total Times Used. When the item is turned in TCMax will say “Attention” then ask you to enter the number of times this item was used during this issue period. That number is added to the Total Times Used, and then the inspections are tested to see if any are overdue. You enter the number of total uses for the next inspection in the Uses Due column of the inspection table. You can also setup an interval in the Uses Interval column that is used during the Inspection Update mode.

Note: the item’s Total Times Used must be greater than zero for this to function.

Ask for quantity of labels when Print Item Label button is clicked​

When checked, and when you click the Print Item Label button, TCMax will ask you how many labels you want, defaulting to one.

Enable Electronic Signature Capture Options (F6)​

With this option enabled and with our LCD signature pad attached to your PC you can capture an electronic signature. After you issue items to someone you hit the F6 key. A list of the items issued to the person within the last two hours will be displayed on the PC screen and the LCD signature pad. The employee signs for the items and clicks the OK button on the LCD signature pad. From that we double encrypt the signature; the second encryption key is based on a list of the items that the person is signing for. The signature is then embedded in an Excel spreadsheet which is immediately saved using the employee name and the date and time.

To later view the Excel spreadsheet and verify that nothing has been edited within the saved spreadsheet you click on Maintenance/Verify Signature on Excel Spreadsheet. You navigate to the spreadsheet and open it. If nothing has been changed, you will see the signature appear.

Automatically clear employee names off the screen after a signature has been captured​

Sign for the item and TCMax clears the main screen.

Enable Fingerprint Identification​

Check this box if you have already installed our fingerprint reader and software.

Wave files ending with this number are used​

This option defaults to “4”. In random mode, each time that you start TCMax the program randomly picks one of the first six sets of wave files to use to say the words “Issue” and “Turn In”, etc. You can force TCMax to use only one of the sets of files each time you start by selecting a number from 1 to 6. Then you can rely on TCMax choosing that set if files with each start. The files are titled “Issu1.wav”, “Issu2.wav”, etc. The number that you select in this option will match the number in the wave file.

Additional Wave File Languages:

  • Spanish
  • French
  • Italian
  • German
  • Mandarin

You are welcome to use the Windows Sound Recorder to re-record any of these wave files to fit your needs. If you re-record them be sure to clip the leading and trailing space from the files, to keep them as short as possible.

Capture IdentityOne Biometric Data​

This option will take over the comm port typically assigned to 2D serial scanners and allow specific IdentityOne Biometric readers to pass credentials to TCMax.

Comm port number for Serial 2-D barcode scanner​

TCMax can communicate with a serial barcode scanner. This requires a COMM Port to be entered.

To disable the Serial Barcode Scanner:

  • Enter a 0 (zero) in the box.

To enable the Serial Barcode Scanner:

  • Determine your COMM Port

Note: To determine the COMM port number you must first have a serial port that you will hook your lock to. If your computer doesn’t have a serial port, install a USB to Serial adapter.

a. Click on the Start button

b. Click on Control Panel

c. Double-Click the System icon

d. Click the Hardware tab

e. Click the Device Manager button

f. Click the + next to Ports (COM & LPT) Next to your COMM port you will see the port number.

Enter your COMM port number into the COMM port number box in TCMax. Now, each time you start TCMax communications the port will be tested. If the communications fail, TCMax will warn you, disable the port software, and continue to work normally without lock communications.

Comm port number for Serial Port Lock Mechanism​

TCMax has the ability to communicate with a serial lock mechanism that when unlocked will automatically place the employee number on the screen of the person that opened the lock. This requires a Comm Port to be entered.

Enter a 0 (zero) to disable this feature.

To determine the Comm port number you must first have a serial port that you will hook your lock to. If your computer doesn’t have a serial port, install a USB to Serial adapter. Then perform the following steps to find your Comm port number.

a. Click on the Start button

b. Click on Control Panel

c. Click the System icon

d. Click the Hardware tab

e. Click the Device Manager button

f. Click the + next to Ports (COM & LPT)

Next to your COMM port you will see the port number. Enter this in the Comm port number box. Each time you start TCMax, communications with the port will be tested. If the communications fails, TCMax will warn you, disable the port software, and continue to work normally without lock communications.

Merge function deletes the destination issued tools​

When you merge databases you sometimes need to delete all issued items and with this option you can do that. Normally this needs to remain unchecked.

Display hose test information​

Checking adds an additional tab to the lower right portion of the screen for tracking hose test data.

Play specific sounds for Broken and Unserviceable items​

Enabling this option will play a Broken or Unserviceable audio file rather than the default “Attention” when interacting with an item marked as broken or unserviceable.
