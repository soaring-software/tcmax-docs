Compute Expressions

This document will provide OData Compute Expressions to elaborate on how you can compute Data based on the criteria entered.

Compute Expression​

KEYVALUE
$computecost mul 7 as totalPrice, quantity add 10 as quantityPlusTen
$selectname, primaryTag, quantity, cost, totalPrice, quantityPlusTen

This $compute expression will take cost and multiply that by 7, then it will take the quantity and add 10 to the quantity. The first value (cost multiplied by 7) will be returned as 'totalPrice'. The second value (quantity add 10) will be returned as 'quantityPlusTen'.

The $select portion of the expression will make the results return with only the properties: 'name', 'quantity', 'cost', 'totalPrice', and 'quantityPlusTen'. No other properties besides those asked for in the select will be returned.

Compute Expression​

KEYVALUE
$computecost mul quantity as totalInventoryPrice
$orderBytotalInventoryPrice ASC

This $compute expression will take the cost and multiply that by the quantity. The result will be returned as 'totalInventoryPrice'.

The $orderBy portion of the expression will return the results in ascending order according to 'totalInventoryPrice' that was computed first.

Compute Expression (Geolocation Querying)​

info

When querying for geolocation information, you must provide a filter that narrows down the result set to only resources that have geolocation information. Querying on resources that don't have geolocation information isn't supported and will result in an error being returned from the server.

An example of such a filter is provided here:

select=id, name, currentDistance

filter=currentDistance ne null

compute=geo.distance(coordinates, geography'POINT(-83.88855 41.58129)') as currentDistance

KEYVALUEDESCRIPTION
$computegeo.distance(coordinates, geography'POINT(-83.02268495482589 39.99817942562295)') as currentLocationA geolocation computed property that can be used in selects, filters, and orderBy parameters.
$filtercurrentLocation gt 2000Example of filtering by a geolocation computed property.
$orderBycurrentLocation descExample of ordering by a geolocation computed property.
$selectid, name, currentLocationExample of selecting a geolocation computed property.

This $compute expression will first find the distance of the given coordinates as currentLocation. Then will filter those results to only return any assets with a currentLocation greater than 2000. Next, the results will be ordered by the currentLocation in descending order. Finally, the results will only return the asset id, name, and currentLocation.
