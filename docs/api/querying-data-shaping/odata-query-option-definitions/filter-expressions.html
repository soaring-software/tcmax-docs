Filter Expressions

This document will contain different OData Filter Expressions that can be utilized.

Logical Operators​

DescriptionSyntax
Equalseq
Not Equalsne
Greater Than gt
Greater Than or Equalge
Less Thanlt
Less Than or Equalle
Oror
Andand
Notnot
Hashas
Inin

Equals​

KEYVALUE
$filtername eq 'insert name'

This $filter expression is going to find all assets where the name property is equal to the value given.

Equals​

KEYVALUE
$filterquantity eq 50

This $filter expression is going to find all assets where the quantity is equal to 50.

Not Equals​

KEYVALUE
$filterquantity ne 1

This $filter expression is going to find all assets where the Quantity does not equal 1.

Not Equals​

KEYVALUE
$filterinventoryDate ne now()

This $filter expression is going to find all assets where the Inventory Date is not equal to now.

Greater Than​

KEYVALUE
$filterquantity gt 10

This $filter expression is going to find all assets where the quantity is greater than 10.

Greater Than or Equal​

KEYVALUE
$filterquantity ge 100

This $filter expression is going to find all assets where the quantity is greater than or equal to 100.

Less Than​

KEYVALUE
$filterquantity lt 25

This $filter expression is going to find all assets where the Quantity is less than 25.

Less Than or Equal​

KEYVALUE
$filterquantity le 35

This $filter expression is going to find all assets where the Quantity is less than or equal to 35.

Or​

KEYVALUE
$filterquantity gt 75 or quantity lt 5

This $filter expression is going to find all assets where the Quantity is greater than 75 or the Quantity is less than 5.

Or​

KEYVALUE
$filtername eq 'insert name' or name eq 'insert name'

This $filter expression is going to find all assets where the Name equals either of the values given.

And​

KEYVALUE
$filterquantity le 1 and contains(name, 'insert name')

This $filter expression is going to find all assets where the quantity is less than or equal to 1 and the name contains the value given.

Not​

KEYVALUE
$filternot children/any()

This $filter expression is going to find all assets (non kits) that do not have children.

Has​

KEYVALUE
$filtercondition has 'Good'

This $filter expression is going to find all assets that have a Condition of 'Good'.

In​

KEYVALUE
$filtername in ('insert name', 'insert name')

This $filter expression is going to find all assets whose name value contains either of the name properties given.

Arithmetic Operators​

DescriptionSyntax
Additionadd
Subtractionsub
Multiplicationmul
Divisiondiv
Modulomod

Addition​

KEYVALUE
$filterquantity add 10 eq 25

This $filter expression is going to find all assets with a Quantity of 15.

Subtraction​

KEYVALUE
$filtercost sub 3.00 eq 30.00

This $filter expression is going to find all assets with a Cost of $33.00.

Multiplication​

KEYVALUE
$filterquantity mul 5 eq 65

This $filter expression is going to find all assets where the Quantity equals 13.

Division​

KEYVALUE
$filterquantity div 3 eq 9

This $filter expression is going to find all assets where the Quantity equals 27, 28, or 29.

Modulo​

KEYVALUE
$filterquantity mod 5 eq 0

This $filter expression is going to find all asset with a Quantity that is exactly divisible by 5.

Grouping​

KEYVALUE
$filter(storageLocation eq 'insert storage location') or (inventoryDate gt 2021-01-01 and quantity lt 15)

This $filter expression is going to find all assets with a Storage Location that is equal to the value given or where the Inventory Date is greater than the date property given and the Quantity is less than 15.

String and Collection Functions​

Concat​

KEYVALUE
$filterconcat(concat(lastName, ','), firstName) eq 'insert last name,insert first name'

This $filter expression is going to append the last name value and first name value to return the results in the form of last name, first name.

Contains​

KEYVALUE
$filtercontains(Name, 'insert name')

This $filter expression is going to find all assets where the name property contains the value given.

Endswith​

KEYVALUE
$filterendswith(Name, 'insert name')

This $filter expression is going to find all assets where the name property ends with the value given.

Indexof​

KEYVALUE
$filterindexof(Name, 'insert name') gt -1

This $filter expression is going to find all assets containing the name property given.

Length​

KEYVALUE
$filterlength(VendorName) eq 6

This $filter expression is going to find all assets with a Vendor Name that equals 6 characters.

Startswith​

KEYVALUE
$filterstartswith(Name, 'insert name')

This $filter expression is going to find all assets where the name property starts with the value given.

Substring​

KEYVALUE
$filtersubstring(Name, 1,2) eq 'insert name'

This $filter expression is going to find all assets where the name property starts at a specified character position and equals the name property given. In this example, the character position would start at 2 and 3 as the index is a zero-based index.

String Functions​

info

By default case insensitive comparisons are used when querying for Data and as such the following filters are typically not needed when filtering resources from the Soaring Software API.

ToLower​

KEYVALUE
$filtertolower(Name) eq 'insert name'

This $filter expression is going find all assets with a Name that equals the given value and convert any uppercase characters to lowercase characters.

ToUpper​

KEYVALUE
$filtertoupper(Name) eq 'INSERT NAME'

This $filter expression is going find all assets with a Name that equals the given value and convert any lowercase characters to uppercase characters.

Trim​

KEYVALUE
$filtertrim(name) eq 'insert name'

This $filter expression is going to find all assets that equal the Name property given and remove all leading and trailing whitespace characters.

Date and Time Functions​

Date​

KEYVALUE
$filterdate(dateReceived) eq YYYY-MM-DD

This $filter expression is going find all assets with a Date Received that equals the Date property given.

Day​

KEYVALUE
$filterday(warrantyExpiration) eq 15

This $filter expression is going to find all assets that have a Warranty Expiration on the 15th day of the month.

Fractionalseconds​

KEYVALUE
$filterfractionalseconds(inventoryDate) lt 0.1

This $filter expression is going to find all assets with an Inventory Date that is less than 0.1 of a fractional second.

Hour​

KEYVALUE
$filterhour(startedChargingOn) eq 19

This $filter expression is going to find all assets with a Started Charging On value for the 19th hour of any day.

Minute​

KEYVALUE
$filterminute(inventoryDate) eq 5

This $filter expression is going to find all assets that have an Inventory Date within the 5th minute of any hour on any day.

Month​

KEYVALUE
$filtermonth(dateReceived) eq 9

This $filter expression is going to find all assets with a Date Received in the month of September.

Now​

KEYVALUE
$filterinventoryDate eq now()

This $filter expression is going to find all assets where the Inventory Date is todays date.

Second​

KEYVALUE
$filtersecond(hose/testDate) eq 20

This $filter expression is going to find all assets with a Hose Test Date within the 20th second of any minute of any hour on any day.

Time​

KEYVALUE
$filtertime(startedChargingOn) eq 02:02:02.561

This $filter expression is going to find all assets that have a Started Charging On value that is equal to the time provided.

Year​

KEYVALUE
$filteryear(dateReceived) eq 2022

This $filter expression is going find all assets that have a Date Received for the year 2022.

Arithmetic Functions​

Ceiling​

KEYVALUE
$filterceiling(cost) eq 50

This $filter expression is going to find all assets with a cost that rounds up to 50.

Floor​

KEYVALUE
$filterfloor(cost) eq 25

This $filter expression is going to find all assets with a cost that rounds down to 25.

Round​

KEYVALUE
$filterround(cost) eq 15

This $filter expression is going to find all assets with a cost that either rounds up or down to 15.

Lambda Operators​

Any​

KEYVALUE
$filterchildren/any(c:c/quantity gt 4)

This $filter expression is going to find all assets that have any children with a quantity greater than the value given, 4.

All​

KEYVALUE
$filterchildren/any() and children/all(c:c/quantity gt 0)

This $filter expression is going to find all assets that have children and have children with a quantity greater than the value given, 0.
